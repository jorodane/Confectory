# Standalone ProjectShell model consumer

Build `project.cpack linux` with the ordinary CLI and run its report's run command. This consumer supplies explicit borrowed project snapshots without any project-loading provider, then checks project→chat direction, null/missing/cross-context rejection, isolated offline drafts/tab/menu state, bounded meaningful logs and independent idempotent close. No EditorHome/ProjectManager/FileStream/Agent/Helper dependency is registered. It proves the role can be reused outside a table or editor visual host; UI remains shared BaseUI.
