# Editor-free rounded game consumer

Build `project.cpack linux` with the existing CLI and run its returned command. This independent model-free consumer verifies paint/hit equivalence over small/large/circle/pill bounds; transparent corner cancellation; pointer and keyboard activation; focus/hide/close and two-View isolation; upward/downward/left/right placement and oversize clamp; non-overlapping opaque clip subtraction. Windows/Android target profiles compile managed code only. No native control, graphical game, APK or IME runtime coverage is claimed by this headless fixture.
