# Local Augment consumer

Optional chief-only proposal UI. This consumer selects a deterministic three-card creative fixture and a real local source/domain verifier; it does not call an LLM or image service. Use a private clone of examples/projects/harvest-game with its pack/target paths pointing at this checkout. Never point the acceptance gate at valuable source: explicit Confirm changes the supplied project.

Build with the existing SDK using `Confectory.Cli.dll build examples/augment/project.cpack linux`. Set `CONFECTORY_AUGMENT_PROJECT` to the private project.cpack, `CONFECTORY_ELEMENT_AUTHORING_HOST` to the built element-authoring DLL, `CONFECTORY_DOTNET` to the installed SDK executable, and `CONFECTORY_AUGMENT_MODE=ui`; run the build report's `run` array. Optional `CONFECTORY_AUGMENT_DIR` is an existing local directory for persistent helper/task/proposal history. Without UI mode, the consumer executes bounded functional acceptance against the private source.

Click one of three cards to select an ordinary Task. Selection changes no source. Cancel retains its record. Type direction/custom prose in the input, then Directed or Custom; Reroll uses no direction, Skip preserves previous batches. Custom prose requires ordinary Task implementation and has no generated scalar plan. Exactly packages only the selected plant ID/yield metadata into the owned YogiBox; no external recipient or sharing.

Stage applies one bounded yield edit to the shared draft. Review supplies a version-bound token. Confirm invokes normal ChangeSet compilation and source CAS. Verify separately runs the local Worker adapter, checks the actual confirmed declaration value and Harvest instance constraints, then uses explicit WorkerTasks.Finish verification. Only verified completed Tasks with unchanged confirmed source contribute active tags. Rarity describes idea deviation, not quality. Effort/risk are separate relative descriptions. Stale/deleted cards are visibly disabled and reject use.

Two desktop windows persist while jobs execute off their native loop. Closing either or SIGINT closes the owner, cancels/joins jobs and preserves durable history; it does not close borrowed workspace/tasks until their owning consumer cleanup. Reopen the same directory/project to inspect preserved history without automatic reroll or task execution. Current text input handles simple characters/backspace; general selection, clipboard and IME editing remain earlier open gates.

Linux actual GUI acceptance: `DISPLAY=:97 python3 tests/gui/augment_x11_spotcheck.py /tmp/augment-final-build.json` with the host/SDK variables above. Windows/android named targets currently compile managed net8.0 only. Native Windows acceptance remains a user spot check. Android equivalent is a single app-owned surface with logical card/history panels, touch cancellation and app/surface pause/resume; native provider, SDK/license/APK/runtime gates remain incomplete. No tool installation or license acceptance is implied.
