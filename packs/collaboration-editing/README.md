# CollaborationEditing

Optional adapter between MultiPlay and existing EditWorkspace/Save/ChangeSet. Explicit participants retain independent local draft workspaces and saved true baselines. Additional sessions/Views of the same participant/context share one workspace with explicit owner references. Closing one does not close the remaining owners. Network intent contains IDs/baseline hashes/revisions/dirty flags, never draft text.

Room Handle is the selected MultiPlay public callback. Authorize is a replaceable Talk/Work/Apply policy; default is trusted local participation, not security isolation. Intent is reported before Confirm; two distinct participants are conflict, three or more clash. Confirm checks Apply policy and real source hash, then uses existing validated source CAS. Concurrent valid proposals cannot both overwrite the same baseline. The losing local draft survives. Poll updates clean units only through Workspace.RefreshClean; dirty units retain text and baseline and receive baseline-change notices.

First milestone is bounded to one existing owned unit per Confirm, shared local project filesystem and at most 64 participant/unit intent entries. Compound creation/registration, automatic 3-way/AST merge, takeover/handoff negotiation, AI HP/turn adjudication, arbitrary P2P and internet deployment remain deferred policies. Selection/resolution is not automatic source application. Disconnect blocks new Confirm but keeps local drafts; reconnect uses the same participant/context and reannounces intent. An already checked in-flight local source transaction finishes its existing CAS/cancellation path; network disconnect is not a rollback or permission-revocation mechanism. Close cancels owned validation, saves local diffs, and releases only its own references. It never deletes source or saves.

Room/server ownership is separate from client/editor ownership. Close the transport server before closing room metadata. Loss of acknowledgement after successful source commit returns confirmed-with-warning; later polls reconcile actual disk hashes. No exactly-once remote delivery or durable distributed log claim.
