# Optional MultiPlay

Public Policy selects bounded loopback TCP/local-star topology, client/frame/time limits; Handle is a replaceable public room callback. Core and RuntimeBase have no networking dependency. OpenServer returns separate server ownership and an opaque endpoint; Connect establishes real TCP client sessions. Four-byte bounded UTF-8 frames, explicit join/leave and request serialization preserve connection state. Extra Views from the same participant do not create a new editing candidate in the collaboration policy.

Only IPv4 loopback is accepted. No internet listener, account, firewall, manifest permission or security settings are changed. Endpoint nonce is an ephemeral local routing capability, not a remote identity/authentication framework. Trusted local callers retain host permissions. This milestone does not implement arbitrary P2P, internet dedicated service, discovery, encryption or host migration.

Disconnect releases one connection; draft/editor/participant ownership belongs to the composing pack. CloseServer cancels listener/connections and waits boundedly for owned workers. Policy/handler errors do not delete source or saves. Complete Android managed compilation is distinct from Android app permissions/native socket execution, which are unverified.
