# HostLoop role

Public elements: `Confectory.HostLoop::Run(string token)->int` `Schedule(string token)->void`, and `Close(string token)->bool`. This role owns host cadence and job scheduling, not editor layout or commands. The actual `examples/editor-home/project.cpack` entry registers closures for its existing Render/Action/input flow and invokes Run. Browser and Android must install their ordinary target host before invoking that same entry.

Private, process-local bridge: `AppContext["Confectory.HostLoop." + token]` is `object[]{Func<bool> step, Action dispose, Action requestStop, Func<bool> isClosed}`. A step returns true while alive. The target host schedules steps, calls Close on stop/error and removes the registry entry only after successful complete disposal. A failed release retains its handle and token for retry; false means an owned command is still pending. Desktop Run owns Console.CancelKeyPress and invokes requestStop, blocks and sleeps two milliseconds between steps; browser RAF and Android app callbacks return immediately from Run. Host callbacks must remain alive until disposal. Dispose removes each resource from its acquisition ledger only after that release succeeds. Repeated calls retry remaining releases; successfully released resources are never released twice. The ledger and callback registration exist before session/control/Owner/surface/native/listener acquisition, and the whole acquisition sequence is protected. Stop/closed waits through further steps for any scheduled job to finish; it never synchronously waits on an unfinished job in an app callback. If Activity destruction directly invokes disposal with an unfinished job, native resources retire immediately and model/session close is deferred to job completion so that the command never accesses a disposed session.

`AppContext["Confectory.HostLoop.Job." + token]` is `object[]{Func<string> work, TaskCompletionSource<string> completion}`. Schedule takes ownership and removes this entry. Desktop/Android run work on a task. Browser runs bounded local metadata/filesystem work synchronously and resolves the completion; unsupported compiler/process operations must be rejected by their owning providers. No thread or browser UI implementation belongs in Core. Run installs the public Close delegate under `Confectory.HostLoop.Close.browser` / `.android`; native hosts use it to distinguish fully closed from pending or failed cleanup. Deferred job faults are observed and reported.

The browser/Android Run bodies dispatch their installed `Func<string,int>` under `Confectory.HostLoop.Run.browser` / `.android`. Missing hosts raise a capability error rather than using a test shell. Window and NativeInput providers still own surface/render/input capabilities. Android app surfaces do not imply desktop OS multiwindow capability.

Increment boundary: reads actual EditorHome Main/MainBody/project manifest and NativeUI Request provider bodies because the old Main used a blocking desktop loop, direct OS folder launching, and an Android-specific shell instead of the actual common product flow. Edits are those files plus this role pack; shared UI Render and Action bodies are unchanged. R1 correction also reads/edits the owning EditorHome.Model CloseSession body: closing blocks commands while public CloseSession retry independently attempts remaining shells/workspaces and manager disposal, clearing the session registry only after success. Failed cleanup is never converted to successfully closed. OpenFolder now requests the owning NativeUI provider operation `open-folder` with JSON `{path}`, allowing target-specific diagnostics.

Rebuild scope: the new role contracts and EditorHome Main import/signature closure, selected HostLoop bodies and selected NativeUI Request body; no Core change. Subsequent target scheduling-body edits should rebuild only the selected provider and affected linked artifact, subject to target compiler cache policy. Functional cross-target product tests and structural/locality tests are separate gates; isolated shell tests are not product target proof.
