# Scoped 2D ballistic/delayed effect pack

Create returns an independent opaque projectile with finite start/target, flight duration, fuse duration and downward gravity. Analytic initial velocity reaches the target plane over flight time; Step advances at most 0.05 seconds, moving through intermediate positions under gravity. Landing only occurs at the declared trajectory terminal plane; there is no general scene collision/physics solver. Residual fixed-step time carries into the fuse then a 0.6-second expanding visible-effect phase; spent instances remain inspectable until Close. Snapshot exposes previous/current/display-interpolated positions, phase/age/radius. Interpolation is explicitly separate from accumulated fixed-step catch-up, which remains RealTimeUpdate policy. No teleport at launch, no Mesh/3D or real-world explosives guidance. Runtime positions are not editor object metadata or table-owned state.
