# ObjectModel 0.1

Create a live caller-owned instance with an explicit type contract, initialized field IDs and actual CLR values. Omitted fields remain unset. Read and Set validate the declared owner lineage, field identity/hash and exact value type/cardinality before accessing the actual instance. Set requires nonempty owner/field and a 64-character lowercase field hash; an invalid contract or value leaves the field unchanged. Create allocates a distinct instance and stores the supplied values directly; arrays and object references are retained without deep copying. No declaration-data hydration, implicit defaults, global instance registry, owner transfer, serialization of live references or lifetime manager is provided.

The object[] state returned as object is an opaque implementation detail; consumers pass it through ordinary object contracts. Typed Blueprint property reads use Read once at the execution node, then retain the result slot. Projects can explicitly bind a compatible Read provider to adapt their own live CLR model. This does not change Blueprint timing or make the implementation's C# this an object receiver.

Typed structural Blueprint Set uses `Set(object target,string owner,string field,string contractHash,object value) -> void` at the execution node, with an explicit receiver and value. General primitive/array and reference single/array fields retain their existing CLR and reference semantics. Compound and function fields are unsupported. Existing `Write(object target,string field,object value)` retains its legacy instance-local contract and does not verify a caller-supplied owner/hash; structural Set never uses it. Set does not expose a field ref/lvalue or perform copy-in/out.
