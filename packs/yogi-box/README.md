# YogiBox

Drafts hold explicit semantic IDs and selected metadata, bounded local RGB captures, and composer text. Exactly receives a caller-selected workspace/IDs/fields. ReserveCapture fixes an owned View and rectangle; CompleteCapture validates matching source/rectangle/dimensions/hash/bytes. Removed or discarded pending captures cannot resurrect. At most 32 items, two images, 16 selected IDs/fields per operation and 512-by-512 images are admitted. Window.Capture only reads an existing consumer-owned desktop client rectangle; no clipboard, arbitrary file or other-window read is implied.

Remove unseals; Seal rejects empty/pending packages. Handoff requires sealing and sends a cloned immutable attachment through an explicitly selected Receive implementation. The default Receive refuses. The example binds a local inspector only. Discard clears/fences the draft while delivered attachments retain their separate lifecycle. The workbench offers Ctrl+Y, scoped LookAtYogi, per-item removal, seal/unseal, a sealed drag to its local inspector drop zone, text, and discard. No external message/image service is called; durable attachment retention and general recipients remain later work.
