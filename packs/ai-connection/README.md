# Inherited AI connection declarations

Connection is a common object contract using Configuration schema (model and credentialReference). Concrete packs expose Connection objects extending it and Settings schemas extending Configuration. These are ordinary source/schema/data declarations; the editor must use its existing View and typed data editing rather than enumerating provider fields. A credentialReference is a public reference name, never a credential value. Selection/configuration is not authorization to read credentials, authenticate, create persistent access, transmit content or incur usage.

Responses supplies endpoint/maxRounds fields and an Agent Provider implementation. Codex supplies executable configuration and an honest unsupported adapter status. No provider/model/auth method is selected by these defaults. Unsupported target fields and liveVerified=false distinguish declaration support from runtime coverage. Inherited pack roles are represented by object/schema contracts; pack manifests themselves do not acquire a new inheritance grammar.

Ledger: new Connection object/Configuration schema; concrete Settings/Connection declarations in Agent.Responses and Agent.Codex. Outside reads: CoreTests' public extends/use-schema/data examples; AndroidExport.Settings ordinary inherited setting objects; Agent provider lifecycle and current metadata View contracts. No Core, editor field enumeration or generic schema executor change. Caller composition must register each chosen pack and its ordinary dependencies.
