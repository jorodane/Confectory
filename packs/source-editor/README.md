# SourceEditor

Reusable arbitrary multiline declaration/body text buffer. Create takes the caller's element/unit ID and source text. Input consumes Unicode scalar text event 12 and navigation/edit keys; Text returns exactly the user buffer. Apply uses public EditWorkspace.SetTextIfRevision, preserving a stale buffer when another draft revision intervenes. No fixed function/body snippet is used by this pack.

In the engine authoring slice F2 opens the selected body/declaration, initially selects all, F3 applies a draft, Escape cancels and F4 selects all. Enter inserts newline, Tab spaces, Backspace/Delete and left/right/Home/End edit the buffer. Save/Confirm remain separate. User-entered function signatures are parsed and link-validated like other declarations. Native View close/reopen retains its buffer; owner shutdown releases it. Full IDE, clipboard, IME composition, syntax coloring and Android native text/authoring integration remain open; ASCII/shifted X11 keys, Unicode API buffers and Win32 scalar delivery are implemented/tested separately.

Snapshot(buffer) returns `[logicalID,text,UTF16 caret offset,all|caret]` from caller-serialized buffer state. Consumers may render a reusable text View without inspecting the private StringBuilder array; worker commands must capture a snapshot on the owning UI dispatcher rather than concurrently reading/mutating a live buffer. Workspace application remains explicit and revision checked.

Refresh(buffer,text) replaces a clean View's displayed text without replacing its token/StringBuilder or clearing selection. It maps the existing UTF16 caret through the changed prefix/suffix span and clamps surrogate boundaries. It never writes a workspace/file; the consumer must first establish that its buffer has no unapplied draft. Editor uses it for clean shared-revision/Confirm refresh, retaining dirty sibling text for CAS conflict handling.

CP18 `BorrowText(source)->string` explicitly lends the public BaseUI text-model handle for a NativeInput View. This establishes interoperability through a public contract rather than assuming an opaque SourceEditor token is BaseUI's private state. Snapshot validation rejects disposed handles. The caller keeps ownership: retire/hide/forget native bindings before closing/replacing a source buffer, and never close the borrowed model independently. Production Editor uses native controls through this bridge; historical Input/F4 APIs remain compatibility/model-test interfaces.
