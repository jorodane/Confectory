# PackWorkspace

Public role: `Open(project, participant, context) -> handle`, `Snapshot(handle) -> JSON`, `Command(handle, operation, payload) -> JSON`, `Close(handle)`. This is a bounded source-view coordinator over EditWorkspace and Save; it owns selection/page/lifetime, never filesystem or source-model semantics. Element Views can consume these contracts without a table.

Snapshot returns explicit identity, selected unit, page/pageSize/total, page metadata and selected text/revision/dirty. Pages contain 32 stable-ID-sorted units. Commands: `select {id}`, `page {page}`, `edit {text,expectedRevision}`, `save {}`, `sources {}`. Edit requires nonnegative revision and at most 1,048,576 UTF-16 characters. A stale edit returns `conflict:true` without discarding the draft. Select preserves every draft. Save persists identity-local draft differences; it does not modify final source. Sources returns `{files:[{id,kind,path,text,revision,dirty}]}` using public List/Read and includes the manifest and body metadata.

Open restores Save once for the shared explicit draft identity. Separate opaque view-owner handles share that draft, while distinct contexts remain independent. Close is idempotent per handle; final-owner cleanup failure retains the owner for retry. No automatic Save/Confirm on close. A different direct EditWorkspace owner must not close a draft borrowed by PackWorkspace while its views remain active; cross-role owner leases are a later shared-contract improvement.

Android/browser target metadata adapters expose Describe/Inspect/Create/Register/SetValue using Core's public Parser. The formatters preserve desktop tool syntax rather than introducing a second source model. They describe only selected owner-root files (symlinks rejected), never follow registries/pins, load code, compile, or claim Confirm. Each source is limited to 1MiB and description to 256 units. Desktop retains its explicit authoring process provider. Declaration editing preserves ID/kind via Inspect; scalar formatting and owned manifest registration preserve the supported statement set. Compiler-backed Confirm remains a separate explicit authoring operation.
