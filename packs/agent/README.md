# Agent execution pack

Optional public Open/Start/Poll/Cancel/CloseRun/Close contracts separate configured AI execution from Helper identity and Worker task ownership. Policy selects bounded runs/events/bytes/timeout/close-wait. Provider(config,execution,operation,payload) is the replaceable integration boundary: open, next, cancel, close. next returns delta/text, wait, completed or error. Execution ID is stable before asynchronous open; cancel must be sticky before open and close idempotent. Implementations must make next bounded/cooperative and permit concurrent cancel. No credentials, account, endpoint, provider SDK or external communication is installed by this pack.

Default Provider explicitly fails execution until selected. Cleanup remains idempotent. Start returns without waiting for provider I/O. Poll drains ordered events with execution/request/sequence identity. One reserved terminal slot reports overflow; oversized events/protocol errors and deadline failures become sanitized error events. Cancel wins under the run lock and prevents late chunks, then requests provider cancellation. Close joins provider work within policy bounds; a noncooperative provider leaves ownership retained and reports failure for retry, rather than claiming it was killed. Same request identity/payload returns the existing run; conflicting payload or retired identity cannot execute again. Agent owns runs; completed IDs remain tombstones until Agent closes. Limits are pack policy, not Core changes.

examples/agent is a deterministic simulated provider consumer, not live model coverage. AgentTests prove stream order, asynchronous start, cancellation, errors, timeouts, queue limits, cleanup, deduplication, default refusal and optional exclusion. Selected consumer Policy/Provider body changes compile one implementation with zero contracts; unselected default changes compile none. Live validation requires an approved concrete provider, model/account configuration, out-of-Git credentials and external-call authorization. SDK/tools/accounts were not installed or configured. Android managed compilation will not imply APK/device coverage.
