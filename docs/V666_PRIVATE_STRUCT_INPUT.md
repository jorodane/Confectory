# Private 본문과 정보 값 입력의 공동 저장

고정 v666 [정보7/8행](V536_I5_6_REMAINING.md)의 기존 private C# 본문·보조 함수 편집과 다른 직접 소유 함수의 정보 값 입력 전환을 한 정보 창·한 Save에 결합한다. 정보별 C# struct·종류 enum·모듈 interface, 명시 async 전환 전 sync caller 오류, 소유권·권한·Review/Confirm·최종 CAS를 유지한다.

유한 종료 기준은 private 코드/helpers의 모든 ABI를 유지하고, 다른 일반 native 함수의 값 입력 하나를 scalar에서 기존 소유 정보 struct로 명시 전환하는 한 흐름이다. 기존 공유 Blueprint 호출자가 이미 가진 정확한 타입의 입력 `packet`을 사용자가 선택하고 이전 연결의 해제를 확인한다. 직접 작성한 본문으로 원래40과 변경 뒤20을 실행하며, native 함수의 지역 복사본을 수정해도 호출자의 `packet.HP=25`가 유지되어야 한다. 공개/native 이름·역할·인자 수·순서·반환, private frame·연결·좌표·정확한64비트 local·독립 원문 bytes/mtime를 보존한다.

각 단독 계획과 전체 assembled C#이 먼저 유효해야 한다. 일반 native 행 하나만 이 값 타입 전환을 허용하고, 정확한 기존 정보 타입·함수 scope proof와 모든 원래 호출자의 명시 대응을 요구한다. private ABI·참조·배열·ref/out·반환·구조·새 import/외부 쓰기를 이 분기로 암묵 허용하지 않는다. 정보 값을 자동 생성하거나 C#·helpers·형변환·binding을 추론하지 않는다. 호출자 import의 해당 타입 표기만 기존 validator가 갱신한다.

기존 version3 `nativeBodyContexts`에 각 명시 계획을 보존하고 기존 `nativeTypeProofs`/`nativeTypeReads`를 정확하게 결합한다. 새 schema·receipt/profile은 없다. 선택 타입과 원래 함수 scope가 읽은 등록 선언은 읽기 전용이다. 기존 경로·읽기 예산 안에서 전체 관측과 최종 CAS를 적용한다. 후속 설명·명시 본문 Save와 cold 복원은 최초 function/source/flow/type 증거를 유지하고 현재 native 서명으로 편집한다. 공유 원문의 불변 관측과 한 검증된 변경을 결합하되 서로 다른 변경 결과는 거절한다.

기존 상세창의 타입 선택·호출 연결·C# 및 private helpers 편집, 취소·Undo/Redo·cold·실패/재시도·응답 유실·늦은 입력·프로젝트/창 경계·Review 취소/Confirm과 원본/정보 정의/등록 관측의 경합을 검사한다. LF/CRLF와 새 패키지·전체 ZIP 복원은 최종 동결본에서 별도 실행한다. 이 한 사용자 흐름의 검증으로 단위를 닫으며 가능한 타입·문맥의 곱을 새 필수 목록으로 늘리지 않는다.

직전 온전한 패키지의 공동 거절과 새 pending 검증기 경계, 이미 Confirm된 source의 구 compiler 실행을 구분한다. 구 Reference parser 및 일반적인 migration/downgrade는 별도 잔여다. 실제 Windows/WebView2·물리 기기·IME/GPU/audio·전체 UI는 미검증이고 과거 초기 빈 화면 원인은 미확정이다. 원본·latest/rollback·증거를 보호하고 main은 사용자 검토와 merge에 남긴다.

이 유한 흐름은 [최종 신규26·재사용17 검증](VALIDATION_V666_PRIVATE_STRUCT_INPUT.md)을 마쳤다.
