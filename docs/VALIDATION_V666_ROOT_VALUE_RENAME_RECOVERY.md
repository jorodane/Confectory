# V666 root 값 입력 이름 저장 복구 검증

이번 단위의 [지원 경계](V2_ROOT_VALUE_RENAME_RECOVERY.md)와 정확한 delta를 먼저
고정한다. 개발 검사와 별도로 최종 코드에서 LF/CRLF 독립 checkout, 실제 .NET 실행과
Chromium UI, 새 Windows 교차 패키지·전체 압축 복원·실패 수명관리를 검증한다.
최종 결과와 보관본의 출처·manifest·공간 측정은 검증 완료 후 이 문서에 기록한다.
실제 Windows apphost/WebView2·모바일·전체 UI·Space 전달 검증은 포함하지 않는다.
