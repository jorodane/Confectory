Intended namespace Confectory.Stage. Public Create/Enter/Transition/Stop/Close/Snapshot/Epoch/Read/Write/Register/Unregister/Advance/Dispatch/Post/Drain/Subscribe/Poll/Unsubscribe/Launch/Observe APIs own a configured per-stage RuntimeBase Owner/scalar state, independent timing clock/schedule, execution session and caller-provided scene/world/view resource token. PrepareResources/StopResources/ReleaseResources/CheckTransition/Event are consumer-selectable hooks. No rendering, physics, editor or RuntimeBase dependency on Stage will be introduced. Scene/render and bounded Ballistic2D contexts are separate consumer components, reusable through a stage-free Preview entry.

Conservative initial policies are explicit: Transition requires keep-prior or stop-prior; returnPolicy is preserve or forbid. No global current stage or hidden singleton. Validate and prepare the target before prior state changes. Stop invalidates lifecycle epochs, removes active dispatch registrations, drops queued callback intents/clock backlog, stops explicitly owned child workers and keeps local world/view/model resources. Close additionally releases resources/subscriptions/Owner/session. View unsubscribe does not stop/destroy Stage. Returning a preserved local context does not revive an external process; child Launch is explicit and asynchronous, separately observed. This is not an atomic cross-process world transition or general scene/physics engine.
