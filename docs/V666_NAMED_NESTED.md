표시 이름과 C# 계약 이름을 구분하고, 본문 텍스트는 사용자가 직접 편집한 것만 선택한다.

기존 ordinary Blueprint caller의 private `graph next`와 각 frame의 code/call/export를
전체 `BlueprintTree`로 검사한다. 공개 입력 이름은 실제 선택된 call에만 대응한다.
private node의 계약·인자, root/자식/형제의 지역값·ID·실행선·출력 소비자와 qualified C#

그룹은 원래 관측에서 각 명시 후보를 먼저 검증한 뒤 기존 overlay/merge와 한 CAS로
저장한다. 정·역순 후보/원래 hash가 같아야 한다. caller graph는 명시 이름 대응 때문에
기존 쓰기 후보가 되지만 C# 기록은 읽기 대상이다. 이미 관측한 owned 원문은 기존
version3 readGuards와 최종 source lease에 결부하며 새 경로나 외부 권한을 만들지 않는다.

후속 owner 설명 Save에서도 native 본문과 변경된 caller graph의 정확한 저장 group을
유지한다. 위치별 타입/역할/수/반환과 out/ref 이름을 유지하는 기존 값 이름 대응만
보존할 수 있으며 임의 ABI 변경을 보존하는 경로가 아니다. caller proof는 실제 소유
native group을 import하는 원래 ordinary graph이어야 한다. 원래 header·중첩/형제 C#
변경, 불완전/변조된 readGuards는 Review/Confirm을 거절하고 입력과 peer를 유지한다.
후속 설명 저장으로 관측을 비우거나 새로운 live source를 기준으로 재배정하지 않는다.
재시작 뒤에는 기존 header 조회가 먼저 필요한 소유 선언을 식별하고 읽는다. 아직 읽지 않은
header를 조회 자체에서 검증하지 않으며, 이어지는 graph·prepare·validate 단계의 전체 원문
검증과 마지막 source lease는 생략하지 않는다.
