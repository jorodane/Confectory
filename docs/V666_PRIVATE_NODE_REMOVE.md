# Private C# 노드의 마지막 상수 값 인자 제거와 공동 저장

기존 v666의 고정7/8행에서 직접 소유 qualified private next code의 두 스칼라 값 인자 중 마지막 long 인자 하나를 명시적으로 제거한다. 원래 연결이 타입을 명시하지 않은 정확한 int32 정수 상수인 유한 범위다. 첫 인자·long 반환·부모 frame/public/native 계약·나머지 연결·노드 ID/좌표·실행선·정확한64비트 local·선택 밖 bytes/mtime를 보존한다. 제거한 인자에 속한 원래 상수 바인딩만 함께 해제하며 다른 값·저장소·부모 계약·실행선을 추측하거나 재연결하지 않는다. C# 본문/helpers는 사용자가 직접 작성한다.

기존 C# Script의 매개변수 영역에서 마지막 선언을 제거한다. 원래 본문에 삭제한 인자 사용이 남으면 실제 compiler CS0103으로 전체 후보를 거절한다. 첫 인자 제거·이름/타입/역할/반환 혼합·여러 인자 제거와 다른 원래 바인딩 종류는 이번 유한 범위 밖이다. 이 조건은 검증된 구현 경계이며 일반 인자 제거의 영구 UX 정책으로 확정하지 않는다. 실제 CLR reflection에서 private 인자 수2→1과 원래40·수동 편집 뒤20을 확인한다.

기존 workspace1·receipt3/nativeBodyContexts와 원래 source/graph/path/hash·읽기 관측·권한·Review/Confirm·최종 CAS를 재사용한다. 현재 metadata의 제거 가능 인자 목록만 추가하며 저장 schema/profile/receipt는 바꾸지 않는다. 취소·Undo/Redo·초안/cold·실패/재시도·응답 유실/늦은 입력·후속 Save·Review/충돌·LF/CRLF·새 package/전체 ZIP 복원을 검사하고 모의 DOM과 실제 Linux engine/Chromium·CLR을 구분한다.

다른 타입/ref-out/반환/입출력 구조·사용되는 반환 대응·다른 바인딩/인자 수와 retained/opaque/import·외부 관측은 잔여다. 정보별 struct·종류 enum·모듈 interface, 명시 async 전환 전 sync caller 오류를 유지한다. 실제 Windows/물리 기기/전체 UI는 미검증으로 구분한다. 최초480초 복원 시간 초과·과거60초 미응답·초기 빈 화면 원인은 미확정이다. main·원본·기존 증거와 latest/rollback을 기존 교대 범위에서 보존한다.
