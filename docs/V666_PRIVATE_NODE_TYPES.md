고정 v666 정보7/8행의 private 노드 자체 ABI에서, 직접 소유한 중첩 next code 노드의 값 인자 하나를 long에서 double로 바꾸고 다른 소유 native 본문과 한 Save·Review/Confirm·최종 CAS에 저장한다. 원래 연결이 타입을 명시하지 않은 정확한 int32 정수 상수인 유한 범위다. 기존 생성기의 상수 해석을 사용하며 상수 JSON이나 바인딩을 바꾸지 않는다. 부모 frame·공개/native 계약과 모든 이름·나머지 타입·역할·인자 수/순서·반환·연결·좌표·정확한64비트 local·선택 밖 원문 bytes/mtime를 유지한다.

기존 C# Script 매개변수 영역에서 long→double을 명시한다. 새 타입에 맞는 본문·보조 함수와 필요한 캐스트는 사용자가 직접 작성한다. 기본값·새 값·바인딩·C#·형변환을 추측하거나 자동 삽입하지 않는다. 단독 후보와 전체 assembled compiler가 모두 유효해야 한다. 기존 이름 변경은 별도로 유지하고 타입+이름/역할/반환/구조의 동시 변경은 이 분기에서 허용하지 않는다.
