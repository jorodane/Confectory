# Private C# 노드의 미사용 long 반환을 void로 바꾸는 공동 저장

기존 v666의 고정 7/8행에서 스칼라 값 인자 1~32개를 갖는 직접 소유 qualified private next code의 미사용 long 반환을 void로 명시한다. 본문/helpers와 다른 소유 native 본문은 사용자가 직접 작성하며 한 Save/Review/Confirm/최종 CAS에 결합한다. 원래 같은 scope의 node arguments·local source·exit 중 하나라도 반환을 쓰면 거절한다. 부모 frame/public/native 계약·모든 인자/연결/좌표/실행선·정확한64비트 local·선택 밖 bytes/mtime를 보존한다. 반환식·사용처·저장소·캐스트·본문을 자동 삭제하거나 변환하지 않는다. 기존 long→double과 이름/인자 타입 편집도 보존한다.

원래40과 편집 뒤20·private void 실행 marker를 실제 CLR에서 검사한다. 이전 long 본문을 그대로 둔 void 후보는 실제 compiler가 거절해야 한다. 유효한 반환 소비 원본 세 종류를 먼저 실행한 뒤 후보가 사용처 보호에서 거절되는지 확인한다. 기존 반환 타입/본문/helpers 영역과 receipt3/nativeBodyContexts/원래 증거를 사용하며 schema·권한을 추가하지 않는다. 취소·Undo/Redo·초안/cold·실패/충돌·응답 유실/늦은 입력·후속 Save·LF/CRLF·새 package/전체 ZIP 복원을 검증한다.

다른 타입/ref-out/반환/입출력 구조·사용되는 반환 대응 및 retained/opaque/import·외부 관측은 잔여다. 정보별 struct·종류 enum·모듈 interface, 명시 async 전환 전 sync caller 오류를 유지한다. 실제 Windows/물리 기기/전체 UI는 미검증으로 구분한다. 최초480초 복원 시간 초과·과거60초 미응답·초기 빈 화면 원인은 미확정으로 유지한다. main·원본·기존 증거와 latest/rollback을 기존 교대 범위에서 보존한다.

이 유한 흐름은 [최종 신규48·재사용0 검증](VALIDATION_V666_PRIVATE_NODE_VOID.md)을 마쳤다.
