## 구현 범위

- 논리 정의는 기본 ‘논리 코드’와 기존 ‘블루프린트 보기’를 유지한다. ‘네이티브 미리보기’는 같은 함수·같은 관측 소스의 실제 `featureBlueprintAssemble` 결과인 C# 본문과 멤버를 읽기 전용으로 표시한다. 전체 프로젝트의 생성 클래스나 컴파일 완료를 꾸며 표시하지 않는다. 소스 버전·원본 파일 충돌, 미저장 입력, 지원하지 않는 문맥 및 생성 실패 시 기존 결과를 현재 결과로 채택하지 않는다.
- 직접 선언된 소유 C# 본문은 단독 ‘네이티브 코드’ 화면에서 편집한다. 자동 Blueprint 변환은 하지 않는다. 기존 명시적 변환 미리보기는 별도 버튼으로 접근하고 취소·재진입할 수 있다. 상속·결합·슬롯 등 아직 지원하지 않는 직접 편집은 기존 명시 경로를 유지한다.
- 네이티브 Save는 선언·구현·본문·manifest의 revision/hash/path/baseline과 원래 체크포인트를 확인한 별도 후보에서 실행한다. 원본 파일 관측은 체크포인트 파일 CAS 안에서도 확인한다. 체크포인트 성공 전에는 live 본문·history를 바꾸지 않는다. Review/Confirm과 마지막 원본 파일 CAS는 기존 경로다.
- 수직 셀은 같은 공유 초안에서 일반 직렬 C# 셀 뒤에 인수 없는 void 동작을 추가하고, 기존 보호 편집기로 실제 본문을 작성한다. 위·아래 이동은 전체 일반 `next` 사슬의 시작점·연결을 하나의 후보로 저장한다. 노드 집합·원래 출구·기존 본문과 계약을 유지하며, 생산자보다 앞서는 명시적 값 참조와 순환·불완전 경로를 거절한다. 최대 63개 일반 셀 범위다. 분기·호출·복사·private/retained·비동기 문맥의 구조 편집을 일괄 지원한다고 표시하지 않는다.
- 접힘·보기 선택은 개인 presentation 상태다. 새 런타임 분기나 프로젝트 그래프/체크포인트 버전을 추가하지 않았다. 네이티브 history는 기존 `source-edit`를 사용하고, Undo로 본문이 원래 바이트가 된 경우에도 기존 history가 참조하는 정상 소유 본문 관측을 보존한다. 기존 reader의 Reference 타입 제약은 이번 작업으로 해소되지 않았다.
