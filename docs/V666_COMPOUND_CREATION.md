# 새 복합 속성과 명시 native 계약·본문 공동 저장

고정 7/8행의 같은 정보 창에서 기존 추가·타입 선택기로 새 단일 복합 속성을 명시하고,
두 함수의 명시 계약·본문·공유 caller 대응 및 정보 설명·아이콘과 한 Save로 결합한다.
게시 a3e36fc4의 생성 단독 검증과 함수 그룹 단독 검증, 결합의 metadata·원래 UI 재현을
먼저 대조한다. 원래 필드 ID·기본값·참조 대상·선택 밖 C#과 정보 정의는 보존한다.

이번 분류는 정확한 typed-definition 키와 단일 compound 계약, 명시한 기존 타입 출처,
안정적인 새 필드 ID·표시명·JSON 기본값만 다룬다. 실제 ID/이름 중복·타입 catalogue와
정확한 sources·기본값·사용처는 InformationDefinitions/FieldTypes의 원래 검증을 통과해야 한다.
없는 값·참조·타입을 추정하거나 자동 변환하지 않는다. 생성에 맞는 전체 명시 owner 계획은
기존 version3 nativeBodyOwnerEdits/nativeBodyOwnerReads에 보관하고 원래 검증기로 재생한다.
소유 원본의 readGuards와 등록 외부 읽기 원본의 기존 최종 CAS lease를 그대로 사용한다.

한 실제 조작은 기존 Leaf2 정보를 선택한 새 복합 필드에 정확한 64비트 Count와 Note를
직접 입력하고 두 native out/return·본문·공유 caller 계획과 한 Save하는 것이다.
등록된 동일 구조 정보도 private fixture에서 읽기 전용으로 대조한다. production 등록이나
권한을 새로 부여하지 않는다. 원래 64행/2..8 native 계획·Review member/read 예산을 유지한다.
