# Private 본문과 원래 호출하는 선택 함수의 공동 저장

고정 v666 [정보7/8행](V536_I5_6_REMAINING.md)의 한 정보 창·한 Save에 기존 private C# 본문/helpers와 그 구현이 원래 호출하는 다른 소유 함수의 C# 본문을 결합하는 유한 단위다. 두 함수의 공개·native·private ABI는 그대로이며 호출 대상의 계약 변경은 포함하지 않는다.

원래 private graph의 일반 call/next 노드는 내부 계산 결과를 두 번째 함수에 전달한다. 두 번째 함수는 같은 Save에서 직접 편집하지만 원래 입력·역할·반환·native 별칭을 유지한다. 원래 root header·고정 fg_call 별칭·typed import·graph/좌표·입출력/locals·caller bytes를 유지하며 새 호출이나 연결을 추론하지 않는다. 원래 프로그램40과 두 단독 계획이 유효하고 기존 게시본의 공동 후보/UI Save만 거절되는 경로를 먼저 측정한다. 수동 두 본문을 확정한 실행20을 종료 기준으로 삼는다.

선택 callee를 허용하는 조건은 직접 소유한 원래 일반 Blueprint 호출, 정확한 원래 typed 계약과 변경되지 않은 callee 공개 서명, 별도로 명시한 native 본문 계획이다. 선택 callee의 계약 변경·private/whole 계획·opaque/retained 문맥·외부/부모 계약은 기존 별도 계획의 경계다. 단독 Contracts/Graphs와 assembled compiler, version3 nativeBodyContexts·전체 원본 readGuards·Review/Confirm·최종 CAS가 각 계획과 합쳐진 실행을 검증한다. 새 schema/receipt·권한·외부 등록·자동 변환은 없다.

취소/Undo·cold·저장 실패/재시도·응답 유실·늦은 입력/후속 Save·창/프로젝트 경계와 원본 경합을 검사한다. LF/CRLF·새 package·전체 ZIP 복원과 이전 일반 helper·역할/반환·whole/retained 회귀를 구분한다. 구 guard의 새 pending 거절과 구 CLI의 확정 일반 source 실행도 별도로 측정한다.

정보별 C# struct·종류 enum·모듈 interface, 명시 async 전환 전 sync caller 오류를 유지한다. 실제 계약이 바뀌는 선택 callee/import·private ABI·retained/opaque import와 다른 역할/반환 구조·외부 관측은 잔여다. 조합별 필수 매트릭스를 늘리지 않는다. 구 Reference reader·실제 Windows/WebView2·물리 기기·전체 UI는 별도이며 초기 빈 화면 원인은 미확정이다. 원본·latest/rollback·증거·main을 보존한다.
