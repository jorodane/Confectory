## 실제 잔여

M4의 Result 없는 소유 next/native/whole-body 본문 어댑터, 새/내부 소유 본문의 명시 전환, property 보조 편집은 남는다. 호환되지 않는 명시 C#/native 호출은 원문/입력을 보존하는 거절이며 자동 호출 어댑터나 소스 재작성을 새 필수 요구로 늘리지 않는다. ref·실제 await·비소유/override 공개 계약 변경의 정상 보호를 미구현으로 세지 않는다. M11/M12는 관련 회귀 외 닫힌 상태를 유지한다. 기존 V2–V9·별도 팩/backend·종류 호환성 결정 및 실제 기기/전체 UI/Space 전달은 별도 잔여다.

새 function completion metadata를 과거 parser가 동일하게 해석한다고 보장하지 않는다. 소스 rollback과 프로젝트/초안 복구를 구분하고 원본·최신 보관본을 함께 보존한다. 개발 요약의 late UI 개수 표기 7은 실제 6으로 정정했으며 최종 증거의 `development-summary-correction.json`에 근거를 남겼다. 최종 단계 수와는 별개다.
