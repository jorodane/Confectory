# v536 정보 속성의 기호·이모지 아이콘

기준은 게시 `caa7e9e`와 저장소 `196c605`의 v536 ZIP이다. 원본의 기존 속성 아이콘
버튼은 `editIconValue(field, anchor, callback, true)`를 열고 선택한 기호/이모지를
적용하거나 `아이콘 없음`으로 해제한다. 이번 단위는 **소유한 정보에 직접 정의된
기존 루트 속성**에서 이 흐름을 기본/독립 properties 창에 연결한다.

원본 팝오버의 선택 목록·문자 입력·닫기·Escape·초점 복귀·아이콘 없음·치수와
기존 속성 Undo를 재사용한다. 새 메뉴·레이아웃·파일 선택 방식은 추가하지 않는다.
이전 요소 아이콘도 같은 팝오버를 사용하며 별도 회귀로 보존한다.

## 저장 의미와 보존 경계

속성의 stable native field name을 키로 한 `editorFieldIcon_<name>`을 해당 정보
정의의 표시 metadata에 저장한다. 기존 `editorFieldName_<name>`과 같은 출처 규칙이며,
표시 이름·순서·데이터 값이나 함수 입출력 식별자를 아이콘으로 바꾸지 않는다.
이 정보의 기존 필드 계약과 원문 hash를 확인하고, 한 grapheme 문자열만 수락한다.
`아이콘 없음`은 그 필드의 아이콘 metadata만 제거한다. 빈 입력의 일반 적용은
원본대로 거절하며 명시적인 해제 버튼과 구별한다.

아이콘과 설명/값은 기존 owner 후보 안에서 함께 검증한다. 모든 관측 source와
최종 CAS·checkpoint 거래가 성공해야 저장되며, 실패·경합·잘못된 마지막 변경은
전체 미적용이다. 파일을 순서대로 부분 저장하지 않는다. 이미 생성된 값·정확한
64비트 수치·참조·주석·부모/외부 원본·요소 아이콘·다른 속성 metadata를 보존한다.

상속 속성은 출처의 아이콘을 읽기 전용으로 표시한다. 현재 정보의 화면에서 부모나
외부 정의를 편집하지 않으며 서버도 직접 정의되지 않은 필드·다른 schema·중첩
path·변경된 계약/hash를 거절한다. 사용자가 기존 삭제로 필드를 실제 제거할 때는
그 필드의 아이콘 metadata도 함께 제거하여 재생성 시 남은 아이콘이 붙지 않게 한다.
참조/값 때문에 기존 삭제가 거절되는 보호는 완화하지 않는다.

응답 유실은 기존 receipt 조회를 먼저 사용한다. 성공 응답 대기 중 새 아이콘은
수락된 glyph·새 schema hash·원래 필드 계약을 receipt에 구별해 보존한다. 재시작은
실제 source 변경을 자동으로 재기준화하지 않는다. 다른 창의 exact64 입력도 유지하며,
그 미적용 입력이 남은 최종 Review는 기존 보호로 거절한다. 사용자 명시 처리 뒤에만
Review/Confirm을 진행한다. 실행 권한이나 프로젝트 접근 범위를 확대하지 않는다.

## 검증과 한계

`evidence/v536-information-property-glyph/focused-verification.json`에 source SHA,
원본 handler와 ZIP hash, 실행 명령·종료코드·확인 수·공간/메모리·리소스 검사를
기록한다. 실제 엔진/렌더러·compiler Confirm은 격리 fixture에서만 수행한다.
로그·화면·원문·프로필은 scratch 증거로 보관하며 Git에 게시하지 않는다.

아이콘 조회/편집은 필드 타입을 변환하지 않는다. 이번 UI 표본은 직접 정보 long
속성·상속 표시·요소 아이콘과 다른 창 입력이며, 가능한 타입/문맥 조합 전체를 새
수용 요구로 추가하지 않는다. 원본 CSS 변경, 사용자 파일 읽기/업로드, AI 호출,
새 계정/권한 또는 실제 사용자 프로젝트 실행은 하지 않는다.

## 정확한 잔여

후속 [새 정보 속성 glyph 수용](VALIDATION_V536_NEW_INFORMATION_PROPERTY_GLYPH.md)은 저장 전
새 직접 루트 정의·값·glyph를 한 후보/CAS로 연결한다. 아래 당시 새 속성 미연결
표시는 이 범위만 해제한다. 중첩 정의·객체 속성·함수/서명 핀·로컬 이미지와 전체
I6 완료로 합산하지 않는다.

- 정보의 직접 기존 루트 속성 glyph와 요소 glyph는 위 범위로 구별한다. 새 미저장
  속성·중첩 속성·객체 인스턴스 속성의 원본 아이콘 편집, 함수/서명 핀 아이콘과
  다른 요소 종류의 원본 팝오버는 아직 미완료다. 이를 정상 금지로 고정하지 않는다.
- 사용자 로컬 PNG/JPG/WebP의 선택·프로젝트 자산 저장·복원은 미연결이다. 이번
  업로드 버튼은 기존 자리에서 비활성으로 유지한다. 개인 파일이나 외부 자료를
  임의 업로드하지 않으며 이미지 생성 제공자를 추가하지 않는다.
- 실제 forwarded 부모·opaque/import 영향 결합의 기존 A6/7 경계, 8행 여러 함수
  문맥, 9행 고급 타입/표시명, B2 실제 배지, M4 async/M11 개별 C#→graph/M12 Root
  실행 분기는 별도 잔여다. 공개 override는 원래 입출력 계약을 유지하고 독립 계약
  복제는 필수 범위가 아니다.
- 전체 UI·실제 Windows/WebView2·DPI/IME·모바일 기기/터치·Library 전달은 미완료다.
  새 RAM Windows 교차 패키지 검사는 실제 Windows 실행이나 파일 전달이 아니다.

집중 8흐름 53확인, 순수 후보 4확인, 요소 아이콘/기존 정보 편집/생산 final CAS 영향 회귀 13확인이 통과했다. 저장된 해제·기존 속성 Undo·부적합 마지막 변경 전체 거절·실제 저장 실패/경합·응답 유실/cold 조회·늦은 glyph/다른 창 입력 보존·명시 compiler Confirm을 확인했다. 원본 팝오버 10영역과 74개 리소스의 바이트/해시도 일치한다.
