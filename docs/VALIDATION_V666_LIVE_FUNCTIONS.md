# live 함수 속성 검증

지원 범위와 호환성은 [live 함수 속성](V666_LIVE_FUNCTIONS.md)을 따른다.
개발 중 게시 코드의 실제 함수 Create 거절을 재현하고, 새 descriptor/CLR 실행과 기존
편집기 수명·source CAS를 확인한다. 최종 동결 코드의 LF/CRLF·새 Windows 교차 패키지와
전체 압축 복원 검증은 별도 독립 실행으로 확정한 뒤 이 기록에 추가한다. 개발 검사와
이전 단위 증거를 최종 통과로 합산하지 않는다.

실제 Windows·물리 기기·전체 UI 검증은 수행하지 않는다. 초기 빈 화면 원인은 미확정이다.
