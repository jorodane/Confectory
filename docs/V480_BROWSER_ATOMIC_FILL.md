# v480 브라우저 Data 다중 행 채우기

기준은 `work/current@9784761`이다. 브라우저 Data는 이미 명시적 소유 객체/필드와 versioned 셀 Apply를 지원한다. 이번에는 독립 InstantTable과 **같은 채우기 폼·이벤트 처리·정확한 JSON 직렬화·단일 `editTable` 호출**을 사용한다. 엔진·모델·공개 편집 API·compiler 실행 의미는 바꾸지 않는다.

## 선택·입력·원자성

채우기 선택 열은 기존 Review 선택과 별개다. 현재 비교 정의의 실제 소유 행만 체크할 수 있고 기본 선택은 없다. 검색·namespace·보기 밀도·문서 재열기가 선택 ID를 늘리거나 대체하지 않는다. 숨긴 선택은 개수로 표시한다. 현재 정의 밖에 남은 선택은 조용히 제거하지 않고 적용을 거부한다. 선택 해제는 명시적 동작이며 입력과 그 버전 기준을 유지한다.

첫 채우기 입력/필드 선택 시 표시한 행의 revision·source SHA-256·resolved view hash를 기존 `tableFill.versions`에 보존한다. Refresh·선택 변경·다른 문서·콜드 복원이 이를 새 버전으로 바꾸지 않는다. 미적용 채우기 상태에서 필드나 비교 구성을 바꾸면 기존 필드·입력·버전을 유지하고 먼저 Apply/Cancel하도록 안내한다. 같은 값의 입력을 고치는 것은 원래 CAS 기준을 그대로 사용한다.

Apply는 명시적으로 선택한 ID 전체를 기존 versioned `editTable`에 **한 번** 전달한다. 기존 lock·모든 후보의 타입/경로/버전 검증·`EditBatch`가 전체 성공 또는 거부를 결정한다. 첫 행이 유효해도 뒤의 행이 stale이면 아무 행도 일부 적용하지 않는다. Int64/배열은 원래 JSON 텍스트를 전달하며 JavaScript Number로 재직렬화하지 않는다. 텍스트는 JSON 문자열로 인코딩한다.

잘못된 타입·원본·스키마 충돌은 채우기 입력·선택·원래 버전·다른 셀의 미적용 입력을 유지한다. 채우기 Cancel은 채우기 입력만 버리고 선택과 다른 셀 입력을 보존한다. 성공한 채우기도 다른 셀 입력을 없애거나 자동으로 재기준화하지 않는다. 상속 때문에 미선택 자식의 effective 값이 달라질 수 있으나 미선택 source에 초안을 쓰는 것은 아니다.

외부 등록 행·다른 종류·미선택 비교 대상은 채우기 체크박스와 쓰기 셀을 받지 않는다. 외부 필터로 이동해도 기존 소유 선택이 다른 행으로 바뀌지 않으며 숨긴 선택 수를 보여준다. 기존 등록 정의의 읽기 전용 경계를 유지한다.

Save는 공유 초안 저장이며 미적용 채우기는 private presentation이다. 셀/채우기 입력이 있으면 비교 Review·해제를 거부한다. 최종 파일은 기존 compiler Review와 명시적 Confirm에서만 반영한다. 비교 해제는 borrowed view만 닫고 그 비교의 선택을 초기화하며 source owner는 유지한다.

## 검증과 남은 범위

실제 Chromium에서 정확한 Int64·문자열·타입 거부, 선택 없음/숨긴 선택/명시적 해제, 두 번째 행 source CAS 및 schema CAS의 원자적 거부, 별도 셀 입력 보존, 외부 읽기 전용, close/reopen·보기 변경·실제 호스트 재시작, Save/compiler Confirm을 검사한다. 최종 고정 원본과 결과·일반 checkout HEAD는 [검증 JSON](validation/v480-browser-fill.json)에 기록한다. 초기/집중 재실행은 최종 고유 검사 수에 합산하지 않는다.

새 계산 열·선택 자동 확장·overflow 정책은 추가하지 않는다. 전체 v480의 남은 작업은 [우선순위별 구현 묶음](V480_REMAINING_WORK.md)에 한 번 정리한다. main·원본 ZIP·Android 설정을 보존하고 실계정·유료 호출은 수행하지 않는다.

최종 고정 제품/테스트 원본은 **7개**다. 같은 원본에서 실제 Chromium 영향 회귀 **11/0/0, 457.566초**, 공유 view/버전·원자적 table 모델 **2/0/0, 54.028초**, Windows/Android 관리 프로필 컴파일 **1/0/0, 131.499초**가 통과했다. 테스트 프로젝트 빌드는 경고·오류 없이 통과했다. 일반 Git checkout·보존 CRLF/새 LF·38개 리소스·실제 Home 시작·변조 거부의 구현 HEAD와 결과는 검증 JSON에 기록한다.
