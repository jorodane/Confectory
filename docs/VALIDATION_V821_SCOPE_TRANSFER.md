# v821 주 흐름과 열린 case 사이 동작 이동

기준은 `8dd3e4a51ff669a9943469e977cff0c0c24b2f8b`이며 고정 검증 소스는 `2f28d7f0d4ab4490d427ce859df090efa9f42827`다.

논리 코드 보기에서 값 연결 없는 일반 void 셀의 손잡이를 잡아 주 흐름 또는 현재 열린 case의 셀 위·아래에 놓을 수 있다. 배치선은 어느 흐름에 놓는지 표시한다. 명시적 종료점을 가진 빈 case는 기존 추가 위치로 받는다. Switch 앞의 직렬 구간과 switch 계속점의 첫 셀 뒤에서 위치를 선택할 수 있다. 계속점의 첫 셀과 switch 자체는 이동하지 않는다. 기존의 같은 흐름 안 이동과 case 탭에 놓아 끝에 배치하는 조작은 유지된다.

엔진은 직접 소유한 같은 물리 root 그래프에서 분리된 두 명시적 case와 직렬 root 연결을 원본에서 다시 확인한다. 옮긴 셀에 한해 필요한 기존 `branchOwner` 정보와 노드 정의 해시를 바꾼다. 노드 파일의 나머지 바이트, 다른 셀·입출력·바인딩, switch의 원래 계속점과 각 case의 종료점은 유지된다. 기존 다중 원본 Save·공유 Undo 이력·Review/Confirm·CAS를 사용한다. 값 의존, 공유 진입, 읽기 전용 원본, 암시적 case, 다른 소유자나 frame에는 이 이동을 제공하지 않는다.
