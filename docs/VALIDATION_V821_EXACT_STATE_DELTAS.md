# V821 정확한 공개 상태 변경분 및 저장 후 응답 (Linux Chromium)

기준: `6307f2ccb86a8cda9857038cd2c4d60887712b42`.
실제 Linux 편집기 호스트와 Chromium, 임시 합성 프로젝트 40/400개.
모든 브라우저 실행은 `tests/run_isolated_browser_test.py` 경유.
Windows 실기 미검증.

## 구현

- 기존 인벤토리 및 관계도 exact-reference 필드는 클라이언트가 이미
  가진 정확한 콘텐츠 토큰이 있을 때만 공개 투영 구성 전에 생략한다.
  호출 전후 범위/리비전 검사는 기존 전체 스냅샷으로 유지한다.
- 관계도는 mounted view별 이전 공개 지도(1MiB 이내)와 정확한 버전에
  묶인다. 크기가 동일한 노드/간선 배열의 변경 행 64개 이내, 64KiB
  이내의 변경분만 전송한다. 길이 변경, 다른 버전, 오래된/없는 증명,
  예산 초과, 이전 클라이언트는 전체 응답이다. 클라이언트는 요청 시
  캡처한 불변 이전 값으로 재구성하고 불변 행의 동일 객체를 유지한다.
- 일반 공개 상태(관계도/인벤토리 제외)는 실제 투영 전체의 SHA-256
  토큰이 정확히 같은 경우만 재사용한다. **리비전이 같다는 이유만으로
  생략하지 않는다.** 클라이언트의 독립 JSON 사본은 UI 수정으로부터
  보호된다. 잘못된 증명은 전체 조회로 복구하고 명령을 재실행하지 않는다.
- 성공한 최종 확정 뒤의 상태/관계도 읽기만 기존 100ms bounded
  completion 경로를 이용한다. 복원 및 작업 사본 Save/Discard의 일반
  호출 경로는 유지한다. 완료 요청의 이미 받은 결과 선택도 적용한다.
- 독립 속성 창 문자열/long 단일 변경은 기존 두 행(객체/변경 없는
  manifest)의 정확한 증명, 두 settlement 검사 및 동일 bound view가
  모두 확보된 뒤에만 기존 통합 최종 확정 경로에 들어간다. 최종 Review
  증명, 파일 CAS, 실제 물리 검증, Worker/relay 범위 검사는 그대로다.

초기 후보에서 내부 범위 검사만 가볍게 하고, 이후 모든 상태 읽기에
완료 응답을 적용했다. 독립 저장은 개선됐지만 복원 표본의 전송량/편집
시간이 불리해 이를 최종 채택하지 않았다. 진단에서 동일 리비전의
일반 공개 상태 약 70KB(presentation ~28KB, editorViews ~22KB)가
반복되었다. 최종 후보는 위의 exact-content 일반 상태 재사용과 성공
후 읽기로 좁힌 방식이다.

## 변동과 재확인

40개 8창 cold의 첫 비교는 명령 1000→1200ms로 느렸다. 순서를
뒤집은 재측정은 첫/마지막 편집 691→666 / 963→892ms,
명령 1266→1100ms, 검색 1754→1661ms였다. 40개 1창 warm
재측정은 첫 편집 210→209ms, 명령 364→451ms, 검색 838→775ms,
cold는 명령 790→793ms였다. 따라서 한 창 warm 명령 준비에는
아직 느린 표본이 남아 있다. 400개 8창 cold 최종 비교는 첫/마지막
편집 664→668 / 1105→1093ms, 명령 1918→1735ms,
검색 2513→2534ms였다.

400개 기본 정수의 전체 준비 시간은 첫 기준선 1104→1198ms,
역순 기준선 1290→1198ms였다. 40개 독립 참조의 전체 준비 시간
1162→1245ms 및 독립 정수 685→715ms도 느린 표본이다.
성공 이후 지연 및 응답량 감소는 일관적이나, 저장 전 호스트 준비
시간까지 모든 경우에 감소한 것은 아니다.

400개 독립 문자열 반복의 호스트 trace에서 Blueprint 호출 18건
중앙값 139→217ms(준비 변동), 이전 Review 7건 84ms/Confirm
7건 118ms에서 최종 통합 Confirm 9건 195ms로 바뀌었다.
해당 trace는 첫 기본 저장 등도 포함한다. 최종 저장 후 별도
관계도 호스트 소비자는 약 17ms, 상태는 약 7ms이며, 그 밖의
대기·전송·렌더링이 남는다. 다음 큰 병목은 실제 Blueprint 준비 및
물리적 확정 전후 검증 비용이다.
