# Private 본문과 out→값 입력의 공동 저장

고정 v666 [정보7/8행](V536_I5_6_REMAINING.md)의 기존 private C# 본문·helpers 편집과 다른 직접 소유 native 함수의 out 하나→값 입력 전환을 한 정보 창·한 Save에 결합한다. [기존 native out→값](V666_NATIVE_OUT_VALUE.md)의 Script 매개변수 영역과 호출 계약 창을 재사용한다. private 공개/프레임/code ABI와 native 이름·자료형·수·순서·다른 역할·반환은 보존한다.

사용자는 새 입력의 리터럴을 직접 지정하고 사라지는 out의 원래 소비자를 같은 타입의 반환값에 명시 대응한다. 기존 입력과 원래 반환은 identity로 유지하고, 입력 해제는 없다. 기본값·저장소·변환·본문·연결을 추측해 만들지 않는다. 직접 작성한 C# 본문·보조 함수만 반영하며 각 단독 계획과 전체 assembled C#이 먼저 유효해야 한다.

유한 종료 기준은 private ABI를 유지한 명시 본문/helpers와 다른 native 함수의 out 하나→값 전환, 새 리터럴과 실제 기존 out 소비자의 반환 대응을 한 후보/CAS에 저장·복원·실행하는 흐름이다. 원래 caller는 실제 out 값40을 반환한다. 편집 뒤 caller20·실제 CLR 값 인자5의 보존·직접 반환25를 확인한다. graph 노드/연결/좌표·정확한64비트 local·독립 원문의 bytes/mtime와 모든 원래 관측을 보존한다. 다른 역할/반환·타입/구조·private ABI·opaque import·외부 쓰기는 별도 범위다. 조합별 새 필수 매트릭스를 만들지 않는다.

각 직접 소유 구현의 기존 단일 target·source import 없음 경계를 유지한다. 역할 변경 행은 하나이고 다른 행은 공개 계약을 유지한다. workspace version1·receipt version3의 nativeBodyContexts와 전체 읽기 관측을 재사용한다. 새 schema/receipt/profile·권한·migration은 추가하지 않는다. 후속 설명과 현재 native 서명으로 명시한 본문 Save도 최초 function/source/flow/역할/호출 대응과 읽기 버전을 유지한다. 이미 적용한 caller 대응은 재제출하지 않는다. Review/Confirm과 최종 모든 원본 CAS가 권위다.

기존 편집기의 취소·Undo/Redo·cold·쓰기 실패/재시도·응답 유실·늦은 입력·창/프로젝트 경계·후속 Save·Review 취소/Confirm과 원본 경합을 검사한다. LF/CRLF 독립 checkout·새 package·전체 ZIP 복원과 기존 값→out/private·struct/pin 이름·whole/retained·native 역할·등록 helper 회귀를 구분한다. 직전 온전한 package의 새 pending 거절과 Confirm된 source의 구 compiler 실행도 별도 측정한다.

정보별 C# struct·종류 enum·모듈 interface와 명시 async 전환 전 sync caller 오류 정책을 유지한다. 구 Reference reader의 제약과 일반 migration/downgrade, 실제 Windows/WebView2·물리 기기·IME/GPU/audio·전체 UI는 이번 완료 주장에 포함하지 않는다. 과거 초기 빈 화면 원인은 미확정이다. 원본·권한·latest/rollback·증거·main을 보호한다.
