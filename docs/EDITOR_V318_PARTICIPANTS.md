# v318 participant recovery increment

The ordinary EditorHome ProjectPack now retains private, unsubmitted Helper conversation and memory inputs, chat/direction inputs and Yogi description text. Helper presentation intents record actual Helper ID, pin state, compose visibility and position per Workspace. Project hiding and Workspace movement preserve those inputs without sending, remembering, recruiting or selecting again. Cold recovery re-reads the existing Helper directory and selected context. Missing membership is reported rather than recreated. Escape closes the pinned composer, then the pinned presentation, retaining its unsent input. Pending layout saves are displayed as pending rather than retaining a stale success label.

Worker windows persist their real task ID. Cold recovery validates the existing task journal against the actual selected project and owner, then uses the ordinary WorkerTasks Open/List/Inspect/Close contracts. Existing running/dispatching interruption and CAS rules remain authoritative. It does not restore a ProjectAI execution owner, approval, provider request or dispatch. Without an owner the actual journal is presented with preparation, execution, recovery and adoption controls disabled. No Worker chat is introduced. Connection windows restore by reading current real connection IDs.

Augmentation reroll opens an explicit new-proposal review through the existing ProjectAI preparation/approval path. Deferral and closing retain the existing real proposal batch. The close label says that proposals remain. Existing task cancellation is not represented as proposal discard. The v318 demo's rotating options, remaining counts, automatic next offer and mock ownership are excluded.

## Remaining v318 boundaries

This increment does not claim complete v318 parity. YogiBox Create is session-only and has no durable item restoration port: only unsubmitted description text is retained, not package contents, transmission authority or sealed status. Its overlay open intent is not restored. Unsubmitted input is not domain memory. AI output/preview/approval/execution owner is not replayed. Task records are inspected when a retained Worker window is restored; a fresh sidebar without that window does not yet automatically load cold task records.

Run viewport migration, pause/step controls and real Run layout retention remain unfinished. Existing actual Run/build/stop contracts and earlier build restrictions remain in place. Proposal custom/skip requires a public consumer connection to existing Augment contracts; selecting task cancellation cannot substitute for discarding a proposal. Conflict merging, usage/billing and delivery policy are undecided. Helper image generation, rich profile/history navigation, Agent usage/account data, co-worker membership and global chat ownership remain unsupported. Market/install/update/publish policy remains unsupported. Terminal object editing, inbox, shared drafts and Save/Review/Confirm are retained. Independent WASM publish performance remains a prior blocker. No real account/model, user PC, device or Site operation occurred.
