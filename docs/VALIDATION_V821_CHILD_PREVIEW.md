## 구현과 권한 경계

기존 root 조립 한 번에서 실제 `FeatureBlueprint.Process`가 생성하는 정확한 자식의 `body`·`members`·해시를, 부모가 자식 요약에서 본문을 제거하기 직전에 선택한다. 다른 emitter, 문자열 절단/부분 재생성, 근사 C#을 쓰지 않는다. 정상 root 조립의 결과와 생성 소스 자체는 그대로다. 선택 필드는 요청/응답에만 있고 프로젝트·graph·노드·체크포인트에 저장하지 않는다.

같은 소유 함수의 physical root, 전체 `/graph:` 경로, root/frame 해시, 전체 source id/revision/hash 및 checkpoint 관측을 서버에서 대조한다. 실제 조립 후에도 원본 source와 checkpoint를 다시 검사한다. 기존 `frame-order` 가드가 증명하는 직접 소유 nested-profile 독립 직렬 tree와 일반 code leaf만 지원하며, 모든 조상·형제의 소유/구조 경계를 유지한다. 기존 깊이·노드·소스 한계를 완화하지 않는다. 기본 편집 화면만 대상이며 copied/inherited/slot/독립 properties-view 문맥은 열지 않는다.

자식 미리보기 API는 선택 경로의 body/members/해시·상태와 확인용 관측만 돌려준다. root 전체 C#, 형제 private 본문, 노드 원문/편집 후보를 응답에 넣지 않는다. 논리 코드·블루프린트 전환과 기존 편집 권한은 유지한다. 미리보기 영역은 읽기 전용 `pre`이며 직접 C# 입력이나 Save 경로를 추가하지 않는다. 소스·입력·경로·checkpoint가 바뀌면 결과를 무효화하고, 실패 시 본문과 멤버의 DOM 텍스트를 모두 비운다. 읽기만 가능한 원본/체크포인트에서도 표시할 수 있지만 읽기 권한이 없으면 거절한다.

공유 진입·분기·opaque·receiver/forwarded·async·슬롯·자식 아래에 다시 graph가 있는 선택 문맥 등은 이 첫 범위에 포함하지 않는다. 상위 root 미리보기로 대체하거나 소유권을 완화하지 않는다. 캐시·보기 presentation을 포함한 모든 파일 쓰기 금지라는 뜻이 아니라, preview가 원본/공유 초안 checkpoint/history를 편집하지 않는다는 뜻이다.

기존 emitter가 해당 자식의 C#을 조립하는 순간에 실제 멤버 출력을 각 셀과 함께 기록한다. 선택 graph의 전체 경로 목록을 소스 맵과 대조하고, C# 본문을 제공한 셀의 경로 목록을 소스 목록과 대조한다. 별도 C# 클래스·헬퍼는 선택 셀별 기여분의 합이 최종 멤버 버퍼와 정확히 일치할 때만 반환한다. 기존 생성 코드 바이트를 그대로 사용해 선택된 본문·멤버·해시만 반환한다. 기존 상속·복사·슬롯·별도 편집 surface 및 비동기/retained/opaque 경계를 유지한다.

독립 LF 체크아웃에서 .NET 복원, Release·MCP·Linux 편집기 빌드를 완료했다. [자식 case 미리보기 검사](../tests/web/v821_child_case_preview_ui.py)의 정상·공유 진입·공유 그래프 세 시나리오와 기존 루트·일반 자식·상위 자식·공유 진입 미리보기 회귀 네 건을 실제 Linux 편집기와 Chromium에서 통과했다. 실제 root 조립 결과에 포함된 선택 본문·멤버·해시와 UI를 대조했고, 양수·음수·기본 경로의 실행 순서와 반환값 합계 14를 미리보기 전후 확인했다. 로컬 ID가 같은 형제가 있어도 선택 범위만 표시됐으며, 형제 파일이 바뀌면 두 코드 영역을 비웠다. 보류한 실제 응답이 나중 입력을 덮지 않았고 재시작 후에도 입력과 그래프·C# 바이트·체크포인트·Undo 이력이 유지됐다.

추가 Linux 엔진 검사에서 다른 활성 프로젝트는 직전에 성공했던 switch 경로 관측을 거절했다. Android 및 WASM metadata 어댑터는 Linux에서 빌드해 입력 바인딩과 미리보기 조립을 계속 거절함을 확인했다. 로그는 `/workspace/scratch/v821-switch-preview.NFgyuOhN`에 있다. Windows 실기, 실제 Android/WASM 런타임, 전체 UI 및 v821 목업 직접 시각 대조는 미실행이다.

다음 독립 후보는 [v821 복합 생성/분해 잔여](V821_UI_BASELINE.md#직접-소유-자식-내부의-기존-일반-셀-순서-편집) 중, 기존 직렬 셀을 복합으로 묶는 제한된 흐름이다. [기존 개별 C# 동작의 내부 흐름](BLUEPRINT_NODE_INTERNAL_FLOW.md)이 원문 보존과 원자 저장의 출발점이다. 여러 셀의 경로·원본 소유와 한 번의 복원이 기존 계약으로 표현되는지 먼저 확인해야 한다. 중간 셀 삭제의 최소 리더 버전과 마지막 셀·탭의 빈 경로 규칙은 별개 결정으로 남아 있다.

## 직접 소유한 일반 C# 메서드 자식

기준 `ae85dc9d`의 Linux 편집기에서 `sync-acyclic-nested-v1` 루트가 직접 소유한 `sync-acyclic-methods-v1` 자식의 C# 편집 창은 열렸고, 같은 자식의 네이티브 미리보기는 지원하지 않는다고 표시됐다. 이제 값 매개변수와 일반 C# 동작만 있는 직렬 자식을 기존 읽기 전용 미리보기에서 열 수 있다. 전체 직렬 트리와 선택한 자식의 물리 소스를 확인하며, 공유 파일, 복사본, retained/context, 비동기와 별도 권한 화면에는 기존 제한이 적용된다. 순서 편집 관측과 저장 형식은 그대로다.

기존 생성기가 각 노드의 실제 메서드 및 보조 멤버를 내보낼 때 그 기여분을 기록한다. 기여분을 합친 문자열이 최종 멤버와 같고, 본문과 소스 맵이 선택한 전체 경로와 일치할 때만 본문·멤버·해시를 반환한다. 관측은 열린 작업공간과 정확한 물리 루트·자식 경로, 전체 원본 관측 및 체크포인트에 묶인다. 실제 컴파일과 적용은 별도 검토·확정의 기존 경계를 따른다.

[`v821_private_method_preview_ui.py`](../tests/web/v821_private_method_preview_ui.py)는 실제 Linux 편집기의 편집 창 취소, 두 형제의 동일 로컬 ID와 서로 다른 메서드/보조 코드, 같은 ID를 가진 다른 프로젝트, 늦은 응답과 미저장 입력, 실제 원본 변경 및 공유 경로 거절을 다룬다. C# 바이트, 체크포인트, 이력 보존을 대조했고 별도 빌드에서 기존 반환값 `24`를 확인했다. 기존 직렬 자식, 상위 자식, 명시적 case 및 미저장 내부 전환의 Linux 회귀도 통과했다. Windows 실기와 v821 목업 시각 대조는 실행하지 않았다.

## 두 단계 깊이의 일반 C# 메서드 자식

직접 소유한 동기 직렬 루트의 두 번째 깊이에 이미 존재하는 일반 값 매개변수 메서드
프레임을 같은 읽기 전용 미리보기에 연결했다. 전체 트리의 기존 검증을 유지하며, 각 코드
원본의 ID는 편집 화면과 같은 전체 `/node:` 경로에서 확인한다. 선택한 프레임의 본문과
메서드·헬퍼 기여분이 실제 생성 결과와 정확히 일치해야 표시한다. 세 단계 이상, 공유·복사본,
상속, 별도 소유 화면, 비동기 및 참조 매개변수 문맥은 기존 지원 경계를 따른다.

`v821_private_method_preview_ui.py nested`는 같은 로컬 ID의 두 프레임과 각 프레임의
메서드 두 개를 사용한다. 논리 코드와 블루프린트에서 진입하고 상위로 돌아오는 경로,
조상·형제 코드 제외, 프로젝트 및 스냅샷 불일치 거절, 원본·초안·Undo 이력 보존을 대조한다.
`nested-alias`는 공유 물리 그래프를 거절하는 경우다. 컴파일과 확정은 기존 별도 동작에서 진행한다.

## 메서드 자식이 있는 상위 복합 프레임

직접 소유한 직렬 상위 프레임이 기존 두 단계 깊이의 일반 메서드 프레임을 포함하면,
같은 읽기 전용 탭에서 상위 실행 본문과 해당 트리의 생성 메서드·헬퍼를 볼 수 있다.
생성기가 기록한 전체 노드·소스·멤버 경로를 선택 트리와 대조하고, 멤버 기여분을
생성 순서대로 합친 문자열이 실제 멤버 버퍼와 일치할 때만 표시한다. 상위 루트 파일과
선택 트리의 각 C# 원본은 고유한 소유 경로를 가져야 한다. 관측은 기존 프로젝트 작업공간,
전체 프레임 경로, 원본 해시와 체크포인트에 묶인다.

`v821_private_method_preview_ui.py parent`는 동일 로컬 ID를 공유하는 두 상위 프레임에서
각각 두 메서드 프레임의 결과를 대조한다. 부모·자식 왕복, 형제·다른 프로젝트의 분리,
자손 원본 변경과 오래된 관측 거절, 체크포인트와 Undo 이력 보존을 검증한다.
`parent-shared-leaf`는 다른 등록 그래프가 같은 C# 파일을 가리킬 때 두 코드 영역을 비워 둔다.
