# V2: C# 편집 안내의 v666 문체

원본은 보관한 `reference/site-ui/Confectory-Editor-Prototype-v666.zip` 내부
`Confectory-v666/dist/blueprint.js`다. 217행의 고정 선언 보호 안내, 190–191행의 enum
형식/항목 안내, 959행의 C# 편집 안내와 991행의 래퍼 안내가 v536의 구어체에서
v666의 “주십시오/습니다” 문체로 바뀌었다.

## 이번 완결 흐름

기존 C# 편집기를 열고 고정 선언 수정 거절·enum 형식 오류를 확인한 뒤, 취소 또는
코드를 초안에 보관하고 저장·Review/Confirm으로 이어지는 흐름이다. 원본과 직접
같은 메시지와 native 전용 조건을 유지한 표현을 [14개 문구 목록](v666-code-editor-copy.json)에
구분해 기록했다. 1~32개 제한·값/ref/out·원문 보호·실제 컴파일 단계는 그대로다.
프로토타입의 “컴파일러는 아직 연결되지 않았습니다”는 실제 구현에 적용하지 않는다.

지정한 문자열 14개/16개 표시 지점과 해당 JS의 자산 무결성 값만 바꾼다. JS 명령과
HTML 구조/선택자, C# 원문·ID·핀/실행 계약·권한·실행 순서·개인 입력/초안 수명·
Review/Confirm·최종 CAS와 backend 원문 진단은 바꾸지 않는다. 동적으로 전달되는
backend 진단을 전역 문자열 치환이나 새 오류 코드로 번역하지 않는다.

오류 상태의 입력 보존/취소·Undo/Redo·cold, 실제 compiler Confirm의 CS0103 원문 응답,
충돌 거절/명시 재시도와 정상 실행을 실제 엔진 UI에서 검증한다.
[최종 검증 기록](VALIDATION_V666_CODE_EDITOR_GUIDANCE.md)에 새 검사/재사용/미실행을 기록한다.

## 유한한 후속

이 단위로 V2 전체를 완료 처리하지 않는다. 노출된 핀/값·일반 저장/확인·탐색/시스템
안내의 대응은 남으며, 아직 없는 V3–V9 화면의 문구는 그 구현 시 원본과 함께 적용한다.
backend 자체의 진단 현지화나 원본에 없는 정책을 새 필수 요구로 늘리지 않는다.
M11/M12/M4의 이미 마감한 구현을 다시 열지 않으며 3D/권한 팩 분리와 이동·실행 분리를
유지한다. 실제 Windows/모바일·전체 UI·Space 전달 검증은 별도다.
