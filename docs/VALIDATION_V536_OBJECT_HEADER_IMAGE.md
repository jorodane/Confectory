# v536 객체 헤더의 로컬 이미지 아이콘

기준 게시본은 `3c0d5b2`다. 원본 v536의 `editObjectIcon`은 선택한 객체의 기존 헤더에서
`editIconValue`를 열고 결과를 그 객체의 icon으로 보관한다. 정보에 한정된 원본 조작이
아니다. 이번 최소 흐름은 **직접 소유 객체 헤더 → 합성 PNG/JPG/WebP 선택 → 적용 →
Undo/Redo → 설명과 Save → 재시작 → Review 취소 → 명시적 Confirm**이다.

## 변경과 재사용

정보 헤더에 이미 연결한 로컬 이미지 선택·128×128 WebP 변환·RIFF/ICCP 검증과 원자 저장을
객체 헤더에도 연결했다. `DeclarationAuthoring.Icon`의 허용 대상과 Browser metadata/렌더러,
기존 헤더의 팝오버 어댑터만 확장한다. 원본 팝오버·레이아웃·CSS·메뉴는 바꾸지 않는다.
변환기·최대 5,000,000바이트 입력·65,500자 metadata 한계·CSP·이미지 decoder 의존성은
앞선 정보 헤더 단위와 동일하다. 원래 파일명/경로나 원본 파일을 저장하지 않고 변환한
WebP 값만 기존 `editorIcon`에 보관한다. 외부 업로드·AI 호출·별도 자산 store는 추가하지 않는다.

객체는 부모·스키마·모듈·구현·typed caller를 가진 기존 fixture의 Slime이다. 직접 사용하는
정보 정의와 부모의 상속 값도 함께 존재한다. 아이콘/설명 Save는 기존 owner 후보·receipt·
checkpoint·최종 CAS를 사용하며 다른 선언/본문을 재작성하거나 참조·입출력 계약을 바꾸지
않는다. 객체의 정확한 `9223372036854775805` 값과 한글 문자열·부모/스키마 원문을 보존한다.
Confirm 전에는 물리 source가 그대로이고, 명시적 compiler Confirm 후에도 객체 선언 한
파일의 표시 metadata/설명만 바뀌어야 한다. 오버라이드는 원래 입출력 계약을 유지하며
독립 계약 복제는 필수 범위에 넣지 않는다.

이번 이미지 저장의 지원 범위는 직접 소유 정보/객체 헤더다. 기능 헤더·속성/함수 카드의
로컬 이미지 연결은 별도 잔여다. 이는 현재 구현 경계이며 새로운 영구 UX 금지 정책이 아니다.
상속/외부 원본이나 사용자가 선택하지 않은 다른 객체를 이미지 변경 대상으로 삼지 않는다.

## 격리 검증

기존 이미지 UI 검사를 객체에도 적용하여 PNG/JPG/WebP 합성 입력·종류/크기/읽기 오류·
팝오버 취소/Escape·늦은 decode·Undo/Redo·cold·원본 팝오버 10영역을 확인한다. 저장 실패·
실제 source 경합·적용/조회 응답 유실·늦은 새 이미지·독립 창과 다른 문서 exact64 입력·
Review/Confirm을 분리한다. 실패와 충돌은 전체 미적용 및 원래 입력/기준 보존이어야 하고,
응답 유실은 기존 receipt 조회로 회수하여 중복 적용하지 않는다.

Native 검사는 부모가 있는 객체와 기존 정보 양쪽에서 opaque/alpha·lossy/lossless·색상
프로필 유무를 확인한다. 잘못된 마지막 image·중복·속성/함수 범위 요청은 전체 거절한다.
기존 정보 이미지·glyph·객체 속성·함수 카드·생산 final CAS는 영향 회귀로 유지한다.
사용자 개인 파일이나 외부 이미지는 검사 입력으로 사용하지 않는다.

최초 Native 도우미는 effective 응답에 없는 parent 필드를 조회해 실패했다. 부모 절이
후보 원문에 유지되는지와 부모의 원본 byte가 그대로인지 검사하도록 도우미를 수정했다.
제품 코드로 없는 필드를 만들거나 검사를 생략하지 않았으며 초기 실패 증거를 보존했다.

## 공간과 남은 범위

사전 예산 200MiB+안전64MiB를 유지하고 검사/빌드를 순차 실행한다. 새 빌드의 전체 JSON
보고서는 RAM에 작성하고 byte/SHA가 같은 gzip 증거와 작은 실행 보고서를 보관한다.
기존 보고서나 cache/보관 빌드를 다시 압축하거나 삭제하지 않는다. 이번 검사에서 직접
만든 fixture/교차 패키지만 증거 보관 뒤 승인된 수명관리로 정리한다.

I6 자체 복합/중첩 정의의 아이콘·다른 원본의 실제 노출 아이콘·기능 헤더와 속성/함수 카드의
로컬 이미지는 남는다. 정보 참조 하위 값의 정상 읽기 전용이나 원래 숨긴 root/mobile 핀은
새 필수 요구가 아니다. forwarded 부모/opaque/import 영향 결합·고정8/9행·B2·M4/M11/M12는
기존 별도 잔여로 유지한다. 전체 UI·실제 Windows apphost/WebView2·모바일 기기 실행·
Library 전달은 미완료다.

집중 7흐름 45확인, Native 3확인, 이미지 renderer/receipt 2확인과 기존 정보 이미지/glyph/객체 속성/함수 카드/final CAS 영향 회귀 36확인이 통과했다. 원본 팝오버 10영역과 75개 리소스 바이트/SHA가 일치한다. 합성 입력 생성에는 검증 환경의 Pillow를 쓰며 제품 이미지 codec 의존성은 추가하지 않는다.
