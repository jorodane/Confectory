`min="240" max="8192"`와 `240–8192 px`를 표시하며 등록값도 같은 축 범위를 검사한다.

실제 소프트웨어 출력에 연결한다. 전체8192×8192는 별도 자원 확대 잔여다.

사용자 C#을 다시 쓰지 않는다. 예제 `examples/custom-axis-output`은64×36으로 시작한다.
