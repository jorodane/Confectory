# v821 분기 포함 복합 호출의 부모 순서 편집

기준은 `9172cfaf391fb53aa5cdf209a44187efc25476e4`이며 검증한 구현은 `d7f1abbff5d0a92da4498f9775190a0b42e1b4cb`다.

직접 소유한 직렬 부모에서, 하나의 기존 switch를 가진 직접 자식 복합 호출을 데스크톱 마우스로 통째로 옮길 수 있다. 지원하는 자식은 두 명시적 case가 각자의 일반 코드 사슬을 실행한 뒤 같은 switch와 기존 직렬 계속점으로 돌아가는 형태다. 부모에는 이 형태의 자식 하나를 허용한다. 부모에서 다른 일반 직렬 셀과 위치를 바꿀 때 기존 손잡이, 배치 표시, 순서 계획, 값 의존성 검사와 Undo를 사용한다.

`BlueprintCellRegion`은 자식의 case 진입과 복귀가 명시적이고 서로 분리되어 있는지 검증한다. 부모의 변경 계획은 기존 노드 집합과 종료점을 포함한 완전한 entry/next 순서만 받는다. 실제 저장의 격리 후보에서도 같은 계획을 검사하고, 기존 소스 관측과 checkpoint, 기존 Review/Confirm·CAS를 거친다. 자식 내부 편집과 미리보기의 기존 진입 조건을 유지한다.

그래프 파일에 쓰기 권한이 없거나 알려진 다른 소유 단위가 같은 파일을 가리키면 드래그와 순서 버튼을 비활성화한다. 이미 잡힌 전체 순서 초안은 일반 연결 편집으로 바뀌지 않으며 같은 일괄 저장 경로에서 거절된다. 쓰기 권한이 돌아오면 같은 입력을 저장할 수 있다. 공유 분기 진입, 암시적 case, 다른 부모나 frame, 모바일 조작은 이 지원 범위 밖이다.
