# 고정 7행: 상속 원본을 보존한 공개 핀 이름·Blueprint 복사

이 단위는 기존 정보 함수의 소유 copy 편집을 이어 연결한다. 함수·핀·본문을 자동으로 추측해 재작성하지 않으며, 원본 v536 화면과 명시적 Review/Confirm을 유지한다.

| 사용자 조작 | 지원 경계 | 원본/권한 보호 |
|---|---|---|
| 저장·확정된 상속 C# copy에서 공개 입력/out 이름과 본문을 함께 편집 | 모든 기존 핀을 같은 위치·타입·전달 역할의 새 공개 이름으로 명시 대응한다. native C# 이름·순서·타입·반환은 유지하며 소유 copy와 호출자의 입력/출력 연결을 같은 후보/CAS에 담는다 | 원래 자식/부모 선언·본문·copy provenance를 유지한다. 부모 본문의 변경 계획이나 모호한 순서·타입/역할 변경은 이 경로로 허용하지 않는다 |
| 상속 Blueprint 구현을 정보 창의 기존 선택창에서 복사 | 실제 body origin의 원본 graph/node/hash를 먼저 검증한다. whole-body 문맥은 부모와 자식의 native 이름·서명·import/scope가 정확히 같을 때만 선택한 copy ID에 연결한다 | child ID를 부모 graph에 대입하여 검증하지 않는다. 원본 graph/node를 다시 쓰거나 hash를 최신 값으로 무조건 바꾸지 않는다 |
| 부모의 whole-body Blueprint가 포함된 프로젝트를 컴파일/Confirm | 컴파일러도 실제 선언 부모의 문맥과 기존 node hash를 사용한다. 상속 node owner는 그대로 부모다 | 독립 선언의 node 파일 빌림은 계속 거절한다. 자식의 다른 native 별칭/import는 추측하지 않고 명시적인 호환 본문을 요구한다 |
| 같은 공개 ABI로 소유 copy의 본문 재편집 | 검증된 copy 증거가 있고 부모 본문 선택이 없으면 부모의 정확한 body/node 원문과 물리 파일 기준을 관측한다. 소유 copy에만 편집 계획을 적용한다 | 부모를 불필요하게 편집 선택하거나 whole-body를 재포맷하도록 요구하지 않는다. 명시된 부모 변경은 기존 쓰기 차단을 통과할 수 없다 |

복사 편집의 기존 whitelist는 그대로다. 직렬 code/call/export와 기존 enum 후처리 형태 밖의 새 그래프 의미·분기/반복·async를 추가하지 않는다. 본문 원문·CRLF·한글·정확한 64비트 수치와 독립 창/프로젝트 문맥을 보존한다.

## 남은 고정 7행

- 등록된 부모와 같은 함수 ID를 유지하면서 그 부모의 기존 타입·핀 수·역할·반환/위치까지 바꾸는 후보는 아직 지원하지 않는다. 현재 전체 pack 검증은 등록된 **모든** 구현을 함수 계약과 대조하므로, 부모를 그대로 두고 불일치 계약을 성공으로 처리하지 않는다. 이 불일치를 숨기거나 부모/외부 원본을 자동 수정하지 않는다.
- 미확정 새 copy와 공개 계약 동시 편집, 외부 함수 ID copy, 여러 target copy의 전체 함수 계약 편집은 기존 guard를 유지한다.
- 부모와 자식의 native 이름/import가 다른 whole-body Blueprint 및 기존 직렬 copy whitelist 밖의 그래프는 명시적 지원 전까지 거절한다.

최신 사용자 결정에 따라 첫 항목의 오버라이드 타입/핀 수/역할/반환 구조 변경 거절은 정상 계약 보호이며 필수 미구현에서 제외한다. 독립 계약 복제/새 계약 ID 기능은 추가하지 않는다. 나머지는 원래 계약을 유지하는 편집만을 대상으로 실제 원본 조작/수용 증거와 대조한다. [확정 정책](V536_OVERRIDE_CONTRACT_POLICY.md)을 우선하며 답변 대기로 표시하지 않는다. 8행 여러 함수 공유 caller와 9행 고급 타입·표시명/native ID는 별도 잔여다. 전체 7행/I5-6/v536 완료가 아니다. 실제 Windows/WebView2·모바일 기기·계정/유료 추론·사용자 프로젝트 실행·Library 전달은 이번 격리 검증과 구분한다.
