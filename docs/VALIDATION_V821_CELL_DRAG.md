## 제품 범위

논리 코드에서 기존 위로·아래로 버튼으로 이동할 수 있는 일반 직렬 셀의 손잡이를 데스크톱 마우스로 끌 수 있다. 같은 root 흐름, 정확한 전체 경로의 직접 소유 일반 child frame, 같은 독립 분기 내부의 순서만 대상으로 한다. 유효한 삽입 경계에는 금색 선과 ‘여기에 놓기’를 표시한다. 앞뒤뿐 아니라 여러 셀을 건너뛰는 이동도 기존 전체 entry/next 계획 하나와 개인 Undo 기록 하나로 처리한다. 기존 버튼·Ctrl+Z/Y·손잡이 Alt+↑/↓를 보존하며 실제 버튼 포커스가 viewport 갱신 때 유지되도록 한다.

버튼과 드래그는 같은 순서 계획·값 의존성 검사를 사용하며 Save는 기존 source proof/checkpoint/소유권·권한·Review/Confirm·CAS 경로를 그대로 쓴다. 엔진, 팩, 프로젝트/저장 형식, 런타임 의미와 권한은 변경하지 않았다. 제품 변경은 UI 3개 파일과 해당 canonical resource identity 3개다. 셀 제목/조건 탭과 접힘 의미를 바꾸거나 중복 설명을 추가하지 않았다.

드래그 세션은 현재 화면·scope·전체 순서·소스 관측·checkpoint·개인 입력과 결합한다. drop 때 다시 대조하며 같은 mount의 일회 토큰만 받는다. Escape, 외부/자기 위치 drop, 잘못된 경계는 순서나 입력을 바꾸지 않는다. 다른 frame·다른 분기·공유 진입·타 소유자·읽기 전용 등 기존 불가 문맥을 열지 않는다. 별도 미저장 이름/값/본문 입력 또는 다른 frame 입력이 있으면 드래그를 비활성화해 보존한다. locals가 있는 흐름, 복합 호출 전체, opaque/async·슬롯 문맥도 이번 드래그 범위에서 제외하고 기존 버튼 지원은 유지한다. 모바일 장기 누르기와 삭제는 추가하지 않는다.
