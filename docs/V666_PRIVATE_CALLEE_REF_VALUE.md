# Private 본문·선택 callee ref→값 공동 저장

고정 v666 [정보7/8행](V536_I5_6_REMAINING.md)의 한 정보 창·한 Save에서 private C# 본문/helpers와 원래 호출하는 직접 소유 callee의 ref 하나→값 전환·수동 C#을 결합하는 유한 단위다. [기존 ref→값 계약](V666_NATIVE_REF_VALUE.md)과 [선택 callee 원본 결합](V666_PRIVATE_CALLEE_OUT_VALUE.md)을 연결한다.

원래 long ref count 하나를 같은 타입의 값 입력으로 명시 전환한다. callee의 nativeAmount/nativeCount·타입·순서·기존 반환을 유지한다. private 함수와 공유 caller는 원래 ref 입력 계약·저장소·바인딩을 유지하며 callee의 새 값 매개변수에 그 값을 읽어 전달한다. 각 caller의 입력·반환 대응을 직접 확인한다. 새 저장소·ref 전달·형변환·C#을 추론하지 않는다. 두 수동 본문/helpers 외 원래 source와 private/frame/code ABI·경로·배치·정확한64비트 locals·선택 밖 bytes/mtime를 보존한다.

온전한 직전 package에서 원래 실행115와 caller ref40, 두 단독 계획의 유효성과 공동 후보 거절을 먼저 측정한다. 원래 scoped caller가 있는 callee의 ref 매개변수 UI 편집 거절·입력/원본 보존도 기록한다. 종료 기준은 두 원래 caller의 동일 입력·반환 대응, 정·역순 같은 후보, 실제 실행15와 caller ref5 보존이다. 직접 private 반환20/ref5와 callee 반환25/값5를 검사한다. callee 본문이 지역 매개변수에999를 써도 원래 caller ref 저장소에 전파되지 않아야 한다. 원래 private 함수의 ref ABI는 바꾸지 않는다.

기존 NativeRoles/Contracts/Graphs와 assembled compiler가 각 원래 계획과 결합 후보를 검증한다. 같은 원래 snapshot에서 authenticated source closure를 결합하고 receipt를 overlay에 rebase하지 않는다. 후속 Save와 cold는 최초 function/source/flow/import·ref→값 선택·물리 읽기 버전을 보존한다. 현재 편집 receipt는 이미 재생 검증한 pending graph의 같은 노드와 일치해야 한다.

기존 매개변수 영역에서 ref 하나를 값으로 직접 바꾸고 본문을 작성한다. 첫 owner Save 전 재진입과 readonly draft의 fresh 복원에서 같은 원본 hash/path·서명·명시 plan의 native 별칭·값 역할·본문을 유지한다. 다른 역할·추가 ref·입력/출력 추론·native 이름/타입 변경은 거절한다. 범용 native available·권한·authored layout은 바꾸지 않는다.

취소/Undo·한 Save·cold·실패/재시도·응답 유실·늦은 입력·독립 창/프로젝트·후속 Save·Review 취소/Confirm·실제 원본 경합을 검사한다. LF/CRLF·새 package/전체 ZIP 복원과 기존 ref→값·private 역할/struct/whole/retained/helper 및 직전 callee out→값 회귀를 구분한다. 구 guard의 새 pending 거절과 구 CLI의 확정 일반 source 실행을 따로 측정한다. schema/workspace1·receipt3/nativeBodyContexts·예산·소유권·권한·최종 CAS를 유지한다.

정보별 struct·종류 enum·모듈 interface와 명시 async 전환 전 sync caller 오류를 유지한다. 다른 callee 계약·private ABI 변경·retained/opaque import·외부 관측은 잔여다. 가능한 조합으로 새 필수 매트릭스를 늘리지 않는다. 구 Reference reader·실제 Windows/WebView2·기기·전체 UI는 별도이며 초기 빈 화면 원인은 미확정이다. 원본·latest/rollback·증거·main을 보존한다.
