## 2026-11-20 확인된 원본 동작과 첫 구현 경계

별도 소비 환경은 위 SHA의 실제 7z를 받아 풀고 `CHANGES-v666-v821`, `dist/blueprint.js`, `dist/function-document.js` 및 포함된 브라우저 단언을 읽었다. 해당 환경의 Chromium은 시작 전 소켓 제약으로 실행되지 않았으므로 이것은 원본 소스·단언 대조이며 목업 시각·실행 검증이 아니다. 현재 엔진 구현 환경의 403이 없어졌다는 뜻도 아니다. 추가 정책 변경·전송 우회 없이 전달된 확인 동작을 기준으로 독립 구현한다.

논리 정의의 기본 보기는 ‘논리 코드’이며 ‘네이티브 미리보기’, ‘블루프린트 보기’ 탭이 있다. 네이티브 정의는 ‘네이티브 코드’ 편집이며 두 논리 보기 탭이 없다. 확장 셀의 입력은 왼쪽, 출력은 오른쪽이고 순서는 실제 실행 연결을 위에서 아래로 따른다. 분기 그룹만 접으면 조건을 나타내는 탭 이름이 남고 패널은 숨는다. 상위 셀을 접으면 소유 분기 탭도 숨고 제목·상태·이동 표시만 남는다. 별도 분기 설명 행을 추가하지 않는다.

첫 제품 단위는 기존 활성 authoring adapter와 같은 graph·공유 초안을 읽는 문서형 보기다. 접힘과 보기 선택은 기존 개인 presentation 저장에만 기록한다. 기존 authored 좌표·노드 배열·연결·저장 schema·실행 의미는 재작성하지 않는다. 지원되는 이름·값·기존 보호 C# 편집기를 재사용하며, 실행 순서 재연결은 기존 Blueprint에서 한다. 새 셀의 이동 표시는 비활성이고 재배치 성공을 모의하지 않는다.

전체 생성 C# 미리보기와 네이티브 정의의 직접 편집 화면은 첫 단위에 포함하지 않는다. 전자는 비활성 탭에 지원 경계를 표시하고 후자는 기존 명시적 Blueprint 전환 화면을 보존한다. 분기 실행은 기존 엔진이 실제 지원하는 계약만 사용한다. `bb7b920f3678ba46e87e48d22a755ba71293ecac`와 배포 metadata 소스 `6ed92688a98847d81db4dd9ec1c80edd41303566`의 앱/호스팅 차이는 이 환경에서 전체 소스를 대조하지 못했으므로 미확정이고 v822로 자동 변경하지 않는다.
