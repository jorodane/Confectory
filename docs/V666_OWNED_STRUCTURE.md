# 기존 소유 자식 구조와 명시 함수 계약의 공동 저장

고정 7/8행의 같은 정보 창에서 기존 직접 소유 자식의 필드 추가·표시·기본값 편집과
두 함수의 명시 native 계약·본문·공유 caller 대응 및 정보 설명·아이콘을 한 Save에 결합한다.
기존 소유 정의 편집과 함수 그룹은 각각 유효하지만 결합 후보는 raw C#/graph 본문을
선언 registry로 해석해 거절됐다. 최종 소유 정의 재검증에는 선언만 overlay하며 원래
본문·graph 업데이트는 compiler와 Save에 그대로 전달한다.

지원 행은 기존 단일 compound 루트의 정확한 owned-definition 계약·owner schema hash·
전체 원래 자식 sources·tree·정확 JSON 값이다. 분류는 권한을 부여하지 않는다.
원래 marker·owner/경로·독점 사용·타입 catalogue·기본값·예산 검증을 그대로 통과해야 한다.
새 자식 source 생성이나 등록 변경·루트 타입/배열수 전환은 이 결합에서 거절한다.
기존 자식 파일 안에 scalar 멤버를 추가하는 조작과 새 자식 schema를 생성하는 조작을 구분한다.

구체적인 검증 조작은 원래 Stats.Power 표시·아이콘, Inner.Title 표시·값과 새 bool 멤버를
변경하고 두 native out/return·본문·caller 대응을 저장하는 것이다. 기존 두 자식 ID·경로와
한글/emoji CRLF 주석, 정확한 64비트 값·명명 정의·원래 등록·선택 밖 C#을 보존한다.
변경 없는 형제 source는 원래 Review/read 멤버로 남을 수 있으나 dirty draft나 물리 쓰기를 만들지 않는다.

기존 version3 receipt에 전체 owner 계획과 원래 readGuards/관측을 보관해 원래 검증기로
재생한다. 저장 응답 중의 늦은 자식 이름·값은 별도 입력으로 남고 cold 뒤 명시 Save한다.
후속 편집은 같은 필드 ID·타입·계층·타입 sources의 값/표시에 한정한다. 현재 draft 기준과
전체 값 검증을 확인하면서 캡처된 원래 schema hash·자식 source 버전·최종 CAS 읽기는
그대로 유지한다. 구조·타입 변경을 값/표시 후속 저장으로 숨기거나 원본 lease를 재기준화하지 않는다.

정상 후보·거절·순서 독립성, 원래 UI Save/Undo/Redo/취소/실패/재시도/응답 유실,
cold·늦은 입력/명시 후속 Save·peer 경합·Review 뒤 source 변경, LF/CRLF 새 restore/build,
새 package와 전체 추출 복원 검사가 통과하면 이 단위를 닫는다. 이전 소유 정의·새 compound
생성과 field/typed-value/scalar receipt·사용처 보호를 회귀 검증하며 임의 타입/문맥 조합을 늘리지 않는다.

다음 고정 잔여는 새 소유 자식 생성/등록의 함수 그룹 결합, opaque/private 명시 C# 계획,
소유 callee·기존 import 변경 그룹과 등록 외부 원본 관측 결합이다. 새 named 정의·루트
전환은 별도 원래 구조 편집 범위다. M11/M12/M4는 회귀 없이 다시 열지 않는다.
정보별 struct·종류 enum·모듈 interface, 명시 async 전환 전 sync caller 오류, 공개 override·
권한·authored layout·Review/Confirm·최종 CAS를 유지한다. main은 사용자 검토/merge 대상으로 둔다.
구 reader downgrade·실제 Windows/WebView2·물리 기기·OS IME·GPU/audio·전체 UI 전수는
이번 자동화와 구분하며 초기 빈 화면 원인은 미확정이다.

이 기존 소유 자식 구조·native 계약 단위의 [최종 신규 48·재사용0 검증과 보관](VALIDATION_V666_OWNED_STRUCTURE.md)을 마쳤다.

[소유 자식 생성·등록과 함수 계획 공동 저장](V666_OWNED_CREATION.md)은 새 소유 root와 기존 트리의 새 자식 추가라는 두 원래 흐름을 원래 출처/missing 기준·생성 소유권·한 후보/CAS에 결합한다. opaque/private 계획과 callee/import·등록 외부 관측은 별도 고정 잔여다.
