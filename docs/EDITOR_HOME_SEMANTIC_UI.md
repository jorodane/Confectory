## State and ownership

Only Main's presentation maps are new: mode by project, row and subsection by selected element, and input/caret buffers by project/element/public row ID. Rows are keyed by the public qualified source/path ID rather than their displayed index, so inserting a field does not attach an existing input to a different field. Positional list paths retain the existing contract; no item identity across reorder is promised. Native widgets and source buffers are retained across presentation switches; no per-frame recreation or table-owned schema model is used. Native text focus is remembered by element/mode/subsection. These unsubmitted presentation inputs are session state, not persisted domain edits; Save persists applied workspace drafts.

Typed actions capture their payload on the UI thread. If the retained raw source differs from the selected draft, Main first explicitly applies it through the existing workspace open/snapshot command with `text` and its CAS revision, then sends the captured action with the refreshed revision only after success in the same project/source. Failure/conflict cancels the queued action and keeps the input. Typed edits refresh the public schema View after completion. No typed operation implicitly sends a second raw text edit. Public Model/PackWorkspace remain the authorities for revisions, ownership, reference direction, changes, validation and Confirm. All added buffers use the existing resource owner/CloseText path; close during a command retains the owned worker until completion.
