# Private 본문과 값 입력→out의 공동 저장

고정 v666 [정보7/8행](V536_I5_6_REMAINING.md)의 기존 private C# 본문·helpers 편집과 다른 직접 소유 native 함수의 값 입력 하나→out 전환을 한 정보 창·한 Save에 결합한다. [기존 native 값→out](V666_NATIVE_VALUE_OUT.md)의 C# Script 매개변수 영역과 명시 호출 대응을 재사용한다. 상세창에 역할 메뉴나 새 레이아웃을 추가하지 않는다.

유한 종료 기준은 private 공개/프레임/code ABI를 그대로 유지하고 다른 일반 native 함수의 기존 scalar 값 인자 하나를 out으로 명시 전환하며, 사용자가 직접 작성한 할당·본문과 원래 caller 입력의 정확한 해제·반환 identity를 한 후보/CAS에 저장·복원·실행하는 한 흐름이다. 원래40과 변경 뒤20을 실행하고 실제 IInvoke의 유일한 out 인자·할당값5·직접 반환25를 확인한다. native 이름·타입·수·순서·다른 역할·반환, graph 노드/연결/좌표·정확한64비트 local·독립 원문 bytes/mtime를 보존한다. 새 out은 자동 연결하지 않는다.

각 단독 계획과 전체 assembled C#이 먼저 유효해야 한다. 각 직접 소유 구현의 기존 단일 target·source import 없음 경계를 유지한다. 일반 native 행 하나만 역할을 바꾸며 다른 행은 계약을 유지한다. 모든 원래 호출자의 입력 해제·기존 출력 identity와 원래 source hash를 요구한다. private ABI·다른 역할/반환·타입/구조·callee/import·외부 쓰기를 이 분기로 암묵 허용하지 않는다. C#·할당·helpers·연결·형변환을 자동 생성하지 않는다. 정보별 struct·종류 enum·모듈 interface와 sync caller의 명시 async 전환 전 오류를 유지한다.

기존 version1 workspace와 version3 receipt의 nativeBodyContexts·전체 읽기 관측으로 검증하며 schema·receipt/profile을 추가하지 않는다. 후속 설명/명시 본문 Save와 cold는 최초 역할·function/source/flow/caller 증거를 유지한다. 현재 native 서명으로 본문을 편집하되 이미 적용한 호출자 대응을 재제출하지 않는다. 공유 원문의 불변 관측과 검증된 한 변경은 결합하고 서로 다른 변경 결과는 거절한다. Review/Confirm과 최종 모든 원본 CAS가 권위다.

원래 C#·private helpers 편집기의 취소·Undo/Redo·cold·실패/재시도·응답 유실·늦은 입력·창/프로젝트 경계·후속 Save·Review 취소/Confirm과 원본 경합을 검사한다. LF/CRLF·새 package/전체 ZIP 복원 및 이전 struct 입력/공개 pin 이름·whole/retained·일반 native 역할/import·등록 helper 회귀를 구분한다. 이 사용자 흐름으로 단위를 닫고 가능한 역할/문맥의 모든 조합을 새 필수로 늘리지 않는다.

직전 온전한 package의 공동 거절과 새 pending 검증기 수용 경계, Confirm된 source의 구 compiler 실행을 구분한다. 구 Reference parser·일반 migration/downgrade는 별도 잔여다. 실제 Windows/WebView2·물리 기기·IME/GPU/audio·전체 UI는 미검증이고 과거 초기 빈 화면 원인은 미확정이다. 원본·권한·latest/rollback·증거·main을 보호한다.
