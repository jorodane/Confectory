# Private 본문과 원래 호출 대상의 명시 공개 pin 이름 변경

고정 v666 [정보7/8행](V536_I5_6_REMAINING.md)의 한 정보 창·한 Save에서 private C# 본문/helpers와 원래 호출하던 다른 소유 함수의 본문·공개 입력 이름 변경을 결합하는 유한 단위다. [계약 불변 선택 callee](V666_PRIVATE_SELECTED_IMPORT.md)에 [기존 명시 pin 이름 대응](V666_PRIVATE_PIN_RENAME.md)을 연결한다.

두 번째 함수의 기존 값 입력 `amount → receivedAmount`를 명시 대응한다. private 구현의 원래 ordinary call과 공유 caller 모두 해당 입력 이름·서명만 갱신하고 기존 바인딩·호출/출력·정확한64비트 locals·좌표를 보존한다. positional `(long,long)` import와 고정 fg_call 별칭·root/native header 및 private/frame/code ABI·nativeAmount/nativeCount·타입/역할/순서/수·반환은 그대로다. C# 본문/helpers는 직접 편집한다. 기존 단독 Contracts/Graphs·assembled compiler와 원래 캡처/전체 읽기·Review/Confirm·최종 CAS가 권위다.

직전 온전한 package에서 원래 실행40과 두 단독 계획이 유효하며 결합 후보/UI Save만 거절되는 경로를 먼저 측정한다. 두 원래 호출자의 정확한 pin 대응·순서 독립 후보와 수동 본문 실행20, 후속 Save/cold에서 최초 function/source/flow·이름 대응과 읽기 버전 보존을 종료 기준으로 삼는다. 타입/역할/반환·pin 수/순서/교환·private ABI 변경이나 opaque/retained·외부 계약을 이 이름 변경에 포함시키지 않는다. 새 호출·C#·별칭·저장소·형변환을 추론하지 않는다.

기존 UI의 취소/Undo·실패/재시도·응답 유실·늦은 입력·창/프로젝트 경계, 실제 원본 경합과 fresh Confirm을 검사한다. LF/CRLF·새 package/전체 ZIP 복원과 완료한 계약 불변 선택 callee·기존 역할/struct/whole/retained/helper 회귀를 구분한다. 구 guard의 새 pending 거절과 구 CLI의 확정 일반 source 실행을 따로 측정한다. schema/workspace version1·receipt version3/nativeBodyContexts와 기존 예산·권한·소유권·authored layout을 유지한다.

이름 변경 callee가 원래 private 호출자의 graph를 갱신하는 경우에만 각 원래 source closure를 독립 재생한다. private receipt를 앞선 내부 overlay에 rebase하지 않는다. 같은 원본의 unchanged 관측은 한 검증된 명시 변경과 결합하며 서로 다른 두 변경 결과는 거절한다. 다른 기존 batch 경로는 유지하고, 최종 결합 프로그램과 원본/읽기 CAS를 다시 검증한다.

저장 뒤 private 본문을 다시 편집할 때에는 현재 metadata가 반환하는 graph receipt를 사용한다. guard는 이미 원래 계획으로 재생 검증한 pending graph의 같은 노드와 그 receipt가 정확히 일치하는지 확인한다. 이는 현재 편집 검증이며, 캡처한 최초 whole receipt/source hash와 물리 읽기 버전은 바꾸지 않는다. 현재 graph에 오래된 편집 receipt를 쓰거나 다른 hash/노드/graph/반환을 제시하면 거절한다.

정보별 C# struct·종류 enum·모듈 interface, 명시 async 전환 전 sync caller 오류를 유지한다. 다른 callee 계약 구조·private ABI·retained/opaque import와 외부 관측은 별도 잔여다. 가능한 조합으로 필수 매트릭스를 늘리지 않는다. 구 Reference reader·Windows/WebView2/물리 기기·전체 UI는 별도이며 초기 빈 화면 원인은 미확정이다. 원본·latest/rollback·증거·main을 보존한다.

이 유한 흐름은 [최종 신규48·재사용0 검증](VALIDATION_V666_PRIVATE_CALLEE_RENAME.md)을 마쳤다.
