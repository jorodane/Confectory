# Private next C# 노드의 사용되지 않는 반환 타입 변경

기존 v6667/8행의 원래 스칼라 값 인자 1~32개를 갖는 직접 소유 qualified private next code에서 long 반환을 double로 명시하고 수동 본문/helpers와 계약 불변 다른 native 본문을 한 Save/Review/Confirm/CAS에 저장한다. 원래 같은 scope의 모든 노드 입력·local source·exit에서 이 반환을 쓰지 않을 때만 이 단위를 허용한다. 부모 frame/public/native 계약, 모든 매개변수·바인딩·좌표·실행선과 선택 밖 원문/mtime는 보존한다. 반환 소비를 제거하거나 새 연결/캐스트/본문을 추측하지 않는다. 반환값 사용처가 있거나 이름·타입·역할·수·순서를 함께 바꾸는 후보는 거절한다.

기존 C# Script의 반환 타입 영역을 명시 편집할 수 있게 하고 취소·Undo/Redo·재진입·cold·실패/충돌·늦은 입력·후속 Save와 기존 receipt3/nativeBodyContexts/원래 증거를 유지한다. 모의 metadata DOM과 실제 Linux Chromium/engine/CLR을 구분한다. 실제 body 실행 stderr marker와 소수 반환을 컴파일/실행하여 private 타입을 확인한다. 새 schema/권한/의존성은 없다. 다른 반환/구조·ref/out 및 retained/opaque와 실제 기기·전체 UI는 잔여다. 최초480초 복원 시간 초과와 초기 빈 화면 원인은 미확정으로 유지한다.

이 유한 흐름은 [최종 신규48·재사용0 검증](VALIDATION_V666_PRIVATE_NODE_RETURNS.md)을 마쳤다.
