## Decisions required for remaining blocked behavior

- Object/schema relation authoring needs an explicit public command, revision/scope guard, and rules for add/replace/remove and multiple applied schemas. Scalar metadata `value` cannot express these relations; `field` edits schema definitions and `data-path` edits data, not application relations.
- Container/list mutations need identity/order, missing-parent, inherited override, null/unset/delete and review-granularity decisions. Existing editable leaves remain usable.
- Global Helper Talk needs an owner for a project-independent Agent and a permission preview covering recruitment template and every owner-private memory item consumed by `Helper::Talk`. Project permissions cannot silently authorize that different content/lifetime.
- Standalone export needs a public job/lifetime/output contract. Existing target choice does not establish one. External Yogi delivery and conflict/charge policies remain outside approval.
