첨부 README의 실행 명령과 데모 저장 데이터는 참고 자료다. 포함된 실행 스크립트를 실행하지 않고 별도 정적 서버와 임시 Chromium에서 화면을 확인했다. 외부 요청은 차단했다. Home, Workspace, 빈 기능, 설명 초안의 내부 노드, 노드 C# 편집, 모듈 인터페이스를 열었으며 페이지 오류는 없었다. 별도 context-menu 캡처에서는 메뉴가 열리지 않았으므로 해당 메뉴 동작의 검증 근거로 사용하지 않는다. 이 프로토타입에는 실제 AI·compiler·외부 실행 엔진이 연결되지 않았다고 README와 화면에 명시되어 있다.

[기존 v424 지도](EDITOR_V424_INTEGRATION.md)의 소유 초안, CAS, Save/Review/Confirm, Helper·Worker, 이력·충돌, 빌드·Run 검증은 유지한다. v480에 바뀐 동작의 수용 결과는 별도 기록한다. v424의 통과 수를 v480 전체 통과 수로 옮기지 않는다.

기능 내부의 원본은 graph와 노드별 파일이고, 최종 C#은 시스템이 조립한다는 [확정 구조](FEATURE_BLUEPRINT_ARCHITECTURE.md)를 유지한다. 완료 노드나 데이터 와이어를 모든 기존 graph의 필수 구조로 고정하지 않는다. v480의 프로토타입 JSON, enum·ref/out·복합 타입 표시는 현재 외부 CELEM ABI의 지원 여부와 대조한다. 새로운 실행 의미가 필요한 동작은 compiler profile과 원본 계약을 먼저 명시하고 검증한다.
