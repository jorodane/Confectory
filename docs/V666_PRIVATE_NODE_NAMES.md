# Private C# 노드 인자 이름과 본문의 공동 저장

고정 v666 정보7/8행에서 private 노드 자체 계약의 첫 유한 단위를 연결한다. 기존 C# Script의 매개변수 영역에서 직접 소유한 중첩 `next` code 노드의 값 인자 이름 하나와 본문·보조 함수를 명시하고, 다른 소유 함수의 계약 불변 native 본문과 한 Save·Review/Confirm·최종 CAS에 저장한다.

원래 인자 위치를 명시 대응으로 사용한다. 이름만 새 값으로 바꾸고 그 위치의 원래 입력 표현식을 그대로 새 키에 보관한다. 모든 타입·값 역할·인자 수와 순서·반환, 부모 private 프레임과 공개/native 계약을 유지한다. 다른 원래 인자 이름을 옮겨 쓰는 순열과 중복 이름을 거절한다. C#·helpers·값·형변환·새 바인딩·저장소를 생성하거나 추측하지 않는다. 새 이름에 맞는 본문은 사용자가 직접 작성하며 단독/전체 assembled compiler가 확인한다.

유한 종료 기준은 원래 `firstNative`를 `deltaNative`로 바꾸고 직접 작성한 private 본문/helpers와 다른 native 본문을 한 후보로 저장·복원·실행하는 흐름이다. 원래40과 편집 뒤20을 실행하고 private code의 서명·인자 키·definitionHash만 새 명시 계획에 맞게 바뀌는지 확인한다. 부모 입력/출력 연결·프레임·노드 ID/좌표·정확한64비트 local·선택 밖 원문 bytes/mtime는 유지한다. 결과20은 명시 본문 편집의 효과이며 이름 변경만으로 결과가 바뀐다는 뜻이 아니다.

기존 workspace1·receipt3의 nativeBodyContexts와 원래 hash/path/whole receipt·읽기 관측을 사용한다. 새 저장 schema/profile/권한은 없다. 현재 metadata의 편집 가능 표시만 추가하며 최종 권위는 원본 소유권·계약 검증과 CAS다. 후속 명시 본문 Save는 현재 노드/그래프 receipt를 검증하고, 최초 원본 서명·본문/그래프 해시와 읽기 버전을 보존한다. 새 pending을 구 검증기가 거절하는 경계와 Confirm된 일반 source의 구 compiler 실행은 구분한다.

취소·Undo/Redo·초안 재진입·cold·실패/재시도·응답 유실·늦은 입력·창/프로젝트 경계·후속 Save·Review 취소/Confirm·post-Review 원본 경합, LF/CRLF와 신규 package/전체 ZIP 복원을 검사한다. 모의 metadata DOM 검사는 실제 엔진·CLR 검사와 구분한다.

이 단위는 private 노드 자체의 모든 ABI를 완료하지 않는다. 타입·ref/out 역할·반환·입출력 구조·부모 frame ABI·root/branch/storage·추가 retained/opaque/copy/import 결합은 별도 잔여다. 정보별 C# struct·종류 enum·모듈 interface와 sync caller의 명시 async 전환 전 오류를 유지한다. 일반 구 Reference reader/migration·실제 Windows/WebView2·물리 기기·IME/GPU/audio·전체 UI는 미검증이고 과거 초기 빈 화면 원인은 미확정이다. main·원본·latest/rollback·기존 증거를 보존한다.

이 유한 흐름은 [최종 신규48·재사용0 검증](VALIDATION_V666_PRIVATE_NODE_NAMES.md)을 마쳤다.
